# source-library Specification

## Purpose
Показывает читателю, какие материалы есть в продукте, и даёт выбрать источник для чтения. Определяет, какие источники видны, как они описаны и какой учебник открывается по умолчанию.

## Requirements

### Requirement: Список источников

Система SHALL показывать читателю список источников библиотеки. В список SHALL попадать только источники, которые опубликованы, разрешены к показу по лицензии и видны читателю по области видимости. В первой версии аккаунтов нет, поэтому видны только источники с общей областью видимости.

#### Scenario: Открытие библиотеки

- **WHEN** читатель открывает библиотеку
- **THEN** система показывает все опубликованные источники с общей областью видимости

#### Scenario: Источник ещё не опубликован

- **GIVEN** источник зарегистрирован, но его обработка не закончена или отложена
- **WHEN** читатель открывает библиотеку
- **THEN** этого источника нет в списке

#### Scenario: Лицензия не разрешает показ

- **GIVEN** у источника лицензия, которая не разрешает показывать текст
- **WHEN** читатель открывает библиотеку
- **THEN** этого источника нет в списке

#### Scenario: Источник с ограниченной областью видимости

- **GIVEN** область видимости источника — отдельный пользователь или группа
- **WHEN** читатель без доступа к этой области открывает библиотеку
- **THEN** этого источника нет в списке

### Requirement: Описание источника

Для каждого источника в списке система SHALL показывать название, автора, год, язык, вид и лицензию. Вид источника SHALL быть одним из: учебник, первоисточник, справочное издание. Если какое-то из этих полей неизвестно, система SHALL явно показывать, что оно не указано, а не оставлять пустое место.

#### Scenario: Полное описание

- **WHEN** читатель смотрит на источник в списке
- **THEN** он видит название, автора, год, язык, вид и лицензию источника

#### Scenario: Неизвестный год

- **GIVEN** год издания источника неизвестен
- **WHEN** читатель смотрит на источник в списке
- **THEN** вместо года показано, что он не указан

#### Scenario: Подробности лицензии

- **WHEN** читатель открывает лицензию источника из списка
- **THEN** он видит название лицензии и ссылку на её текст

### Requirement: Фильтр по виду источника

Система SHALL позволять отфильтровать список по виду источника. Можно выбрать один или несколько видов, и тогда в списке остаются только источники выбранных видов.

#### Scenario: Только учебники

- **WHEN** читатель выбирает в фильтре вид «учебник»
- **THEN** в списке остаются только учебники

#### Scenario: Несколько видов

- **WHEN** читатель выбирает виды «учебник» и «первоисточник»
- **THEN** в списке остаются источники обоих видов, а справочные издания скрыты

### Requirement: Фильтр по языку

Система SHALL позволять отфильтровать список по языку источника. Выбрать можно только те языки, на которых в библиотеке есть хотя бы один видимый источник.

#### Scenario: Один язык

- **WHEN** читатель выбирает в фильтре русский язык
- **THEN** в списке остаются только источники на русском

#### Scenario: Доступные языки

- **GIVEN** в библиотеке есть видимые источники только на русском и английском
- **WHEN** читатель открывает фильтр по языку
- **THEN** в фильтре предлагаются только русский и английский

### Requirement: Поиск по названию и автору

Система SHALL позволять искать источник по строке запроса: в списке остаются источники, у которых запрос встречается в названии или в имени автора. Поиск SHALL находить совпадение по части слова, не различать регистр и не различать «е» и «ё». Список SHALL обновляться по мере ввода запроса.

#### Scenario: Поиск по автору

- **GIVEN** в библиотеке есть учебник, автор которого «В. Ф. Асмус»
- **WHEN** читатель вводит «асмус»
- **THEN** этот учебник остаётся в списке

#### Scenario: Поиск по части названия

- **WHEN** читатель вводит «познан»
- **THEN** в списке остаются источники, в названии которых есть слова вроде «познание» или «познания»

#### Scenario: Буква «ё»

- **GIVEN** в названии источника есть буква «ё»
- **WHEN** читатель вводит это слово через «е»
- **THEN** источник находится

#### Scenario: Очистка запроса

- **WHEN** читатель очищает строку поиска
- **THEN** в списке снова все источники, которые подходят под выбранные фильтры

### Requirement: Сочетание поиска и фильтров

Поиск, фильтр по виду и фильтр по языку SHALL действовать вместе: в списке остаются источники, которые подходят под запрос и под оба фильтра. Система SHALL позволять одним действием сбросить и запрос, и фильтры. Если подходящих источников нет, система SHALL сообщать об этом и предлагать сбросить запрос и фильтры.

#### Scenario: Оба фильтра

- **WHEN** читатель выбирает вид «учебник» и английский язык
- **THEN** в списке остаются только учебники на английском

#### Scenario: Запрос и фильтр

- **WHEN** читатель выбирает вид «первоисточник» и вводит «кант»
- **THEN** в списке остаются только первоисточники, где «кант» есть в названии или в имени автора

#### Scenario: Пустой результат

- **GIVEN** в библиотеке нет учебников на немецком
- **WHEN** читатель выбирает вид «учебник» и немецкий язык
- **THEN** система сообщает, что подходящих источников нет, и предлагает сбросить запрос и фильтры

#### Scenario: Сброс

- **WHEN** читатель сбрасывает запрос и фильтры
- **THEN** строка поиска пуста, фильтры сняты, в списке снова все видимые источники

### Requirement: Выбор источника для чтения

Система SHALL позволять выбрать любой источник из списка для чтения. Выбранный источник становится текущим: его читатель видит на экране чтения, и на него опираются возможности, которые работают «по выбранному учебнику».

#### Scenario: Выбор источника

- **WHEN** читатель выбирает источник в списке
- **THEN** система открывает этот источник для чтения и делает его текущим

#### Scenario: Текущий источник виден в библиотеке

- **WHEN** читатель возвращается в библиотеку
- **THEN** текущий источник отмечен в списке

### Requirement: Учебник по умолчанию

В библиотеке SHALL быть назначен один учебник по умолчанию. Если читатель ещё не выбирал источник, текущим SHALL быть учебник по умолчанию.

#### Scenario: Первый вход

- **GIVEN** читатель впервые открывает продукт в этом браузере
- **WHEN** он переходит к чтению, не выбрав источник
- **THEN** открывается учебник по умолчанию

### Requirement: Запоминание выбранного источника

Система SHALL запоминать текущий источник в браузере читателя и восстанавливать его при следующем визите. Если запомненный источник больше не виден в библиотеке, система SHALL открывать учебник по умолчанию и сообщать читателю, что прежний источник недоступен.

#### Scenario: Повторный визит

- **GIVEN** читатель выбрал источник и закрыл вкладку
- **WHEN** он снова открывает продукт в том же браузере
- **THEN** текущим остаётся выбранный им источник

#### Scenario: Запомненный источник снят с публикации

- **GIVEN** запомненный источник больше не виден в библиотеке
- **WHEN** читатель снова открывает продукт
- **THEN** открывается учебник по умолчанию, и система сообщает, что прежний источник недоступен

#### Scenario: Другой браузер

- **GIVEN** читатель выбирал источник в одном браузере
- **WHEN** он открывает продукт в другом браузере
- **THEN** текущим будет учебник по умолчанию

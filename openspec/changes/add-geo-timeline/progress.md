### 4. Что не принято и почему

- **Удаление мест при откате** (ревьювер: «спека „откатывается целиком“»; ведущий разрешил любой из двух путей). Выбрано честное «утверждения откатываются, места остаются». Причины: в API сервиса нет удаления сущностей, а новая операция ради пустых мест шире изменения; место без утверждений на глобус не попадает.
- **Сущности без годов жизни** (тестировщик: «без даты рождения»). Отдельного правила нет: в слой попадают только `people` из `/map`, а там у персоны всегда есть годы жизни. Записано фразой в требовании.
- **Закрытые источники и регион в слое** (тестировщик). Отдельной фильтрации по региону нет. Слой не отдаёт цитат, id абзацев и текстов (нормативное требование и тест). Охват закрытого учебника через `only_textbook` — существующая проблема `/map` (задача 10.1).
- **Подписи `aria-hidden` у отметок при `role="application"`.** Оставлены: текстовая альтернатива — список. Ревьювер просил только роль и `aria-roledescription`.
- **Перевод `definition` на флаг `requires_attribution`** — не делается здесь (поведение определения не меняем), записано в «Рисках».

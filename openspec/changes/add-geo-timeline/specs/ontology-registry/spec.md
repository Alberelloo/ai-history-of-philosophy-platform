## ADDED Requirements

### Requirement: Координаты места

Реестр SHALL содержать значение-свойство «координаты» у места: широта и долгота в градусах. Сервер SHALL принимать координаты, только если оба значения — числа, широта в пределах −90…90 и долгота в пределах −180…180. Сервер SHALL хранить их округлёнными до 0,01°. Иное значение SHALL отклоняться с сообщением о допустимых пределах и событием `knowledge.statement.refused` с полями `type` и `reason`. Координаты SHALL записываться только с атрибуцией: без атрибуции утверждение SHALL отклоняться. Требование атрибуции SHALL задаваться флагом типа связи в реестре, а не проверкой по коду типа. Координаты MUST NOT входить в схему вывода для модели.

#### Scenario: Координаты Кёнигсберга

- **WHEN** для места «Кёнигсберг» записываются координаты 54.7104, 20.5101 с атрибуцией Wikidata
- **THEN** утверждение сохранено со значением `{lat: 54.71, lon: 20.51}`

#### Scenario: Вне пределов

- **WHEN** для места записываются координаты 95, 20
- **THEN** утверждение отклонено с сообщением о пределах широты, в журнале `knowledge.statement.refused` с `type=coordinates`

#### Scenario: Без атрибуции

- **WHEN** координаты места записываются без атрибуции
- **THEN** утверждение отклонено, в журнале `knowledge.statement.refused` с `type=coordinates`

#### Scenario: Не для модели

- **WHEN** строится схема вывода для модели по всем семействам
- **THEN** в схеме нет типа `coordinates`

### Requirement: Вид места в биографии

У связи «жил в» SHALL быть уточнитель «вид места» со значениями из списка: рождение, смерть, деятельность, проживание. Значение вне списка SHALL отклоняться. Уточнитель SHALL сочетаться с уточнителем «время». Запись без вида места SHALL оставаться допустимой: такие записи уже есть.

#### Scenario: Место деятельности со временем

- **WHEN** для Декарта записывается «жил в» Амстердам с видом «деятельность» и временем 1628–1649
- **THEN** утверждение сохранено с обоими уточнителями

#### Scenario: Вид вне списка

- **WHEN** для «жил в» записывается вид места «отпуск»
- **THEN** утверждение отклонено с сообщением о допустимых значениях, в журнале `knowledge.statement.refused` с `type=lived_in`

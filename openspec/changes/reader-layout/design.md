# Design

Задание и все величины — в [docs/design/features/reader-panels.md](../../../docs/design/features/reader-panels.md) (этап 1, раздел 16). Здесь — решения по коду, которых нет в документе.

## Контекст

Изменение делается на ветке `claude/reader-design`, в которую уже слит `claude/design-system` (redesign-navigation, PR #28): в дереве есть `Sidebar.tsx`, `SoonPage.tsx`, хранилище формата 3, заглушки необработанных частей. Этап 0 (слияние PR #28) выполнен коммитом слияния.

## Раскладка K1–K4

Свободная ширина `A = ширина окна − навигация − панель`, где панель — 448 (режим «сдвиг»), 48 (режим «полоска») или 0 (закрыта). Выбирается первая раскладка, которая помещается с колонкой текста не уже `measure-min` (62ch):

| Раскладка | Состав | Нужно `A` ≥ |
|---|---|---|
| K1 | оглавление 208–272 · 48 · текст · 40 · поле 288 | 1328 |
| K2 | оглавление 208–272 · 48 · текст | 1000 |
| K3 | полоса 56 · 40 · текст | 840 |
| K4 | текст (без оглавления, кнопка «Оглавление») | 744 |

Лишняя ширина раздаётся: сначала колонка текста до `measure` (68ch), затем оглавление до 272px, остаток поровну между внешними отступами.

Расчёт ведётся по фактическим ширинам элементов (`getComputedStyle`/`ResizeObserver` на рабочей области), а не по таблице px, поэтому раскладка верна для любого кегля и масштаба. Пересчёт — при изменении ширины окна, открытии/закрытии панели, закреплении навигации.

## Режим панели

- `A` (с учётом открытой панели 448 и закреплённой навигации 280) < 744 — навигация временно сворачивается до 56px; `sidebarPinned` в хранилище не меняется, кнопка «Закрепить» получает `aria-disabled="true"`.
- Окно ≥1280px — панель «сдвигает» колонки (занимает 448px у правого края, рабочая область сужается).
- Окно 1024–1279px — полоска 48px у правого края на всю высоту; раскрытая панель 448px лежит поверх правой части текста с тенью `shadow-panel`, раскладка не меняется. Сворачивается в полоску по щелчку/фокусу в тексте, Esc и кнопке «Свернуть».

## Привязка места чтения (2.5)

Перед сменой раскладки в `useLayoutEffect` запоминается опорный абзац `[data-paragraph]` (нижний край ниже `scroll-padding-top`, или абзац-открыватель панели) и его расстояние от верха окна. Колонки меняют ширину одним шагом, панель въезжает (`translateX(16px)` → 0, `opacity` 0 → 1, `dur-slow`). После смены раскладки, в том же кадре, прокрутка выставляется так, чтобы опорный абзац был на прежнем расстоянии. `overflow-anchor: none` на корне прокрутки.

Ширина колонок не анимируется (Р7): анимируются только появление/уход панели и разворот полоски.

## Состояние панели выше ReaderPage

В `App.tsx` заводится состояние панели: `{ mode: "assistant" | "card" | null, stack, cardId, … }`, передаваемое в `ReaderPage`. Это нужно для «панель остаётся открытой при переходе в другую главу/книгу» и для ссылок на абзацы (этапы 3–4). В этапе 1 стек используется минимально: карточка и ассистент кладут элемент наверх, «Назад» снимает верхний.

## Токены и масштаб (9.7)

`docs/design/tokens.json` — источник. Размеры переводятся в `rem` (навигация 3.5rem/17.5rem, оглавление 13–17rem, полоса 3.5rem, поле 18rem, панель 28rem, полоска 3rem, окно 23rem, промежутки `space-*`), добавляются `measure-min: 62ch` и `panel-strip: 3rem`. Корневой кегль `html { font-size: clamp(100%, 53.1% + 0.39vw, 116%) }` добавляется в `styles.css` (не в генератор токенов). `tokens.css` перегенерируется `python scripts/design_tokens.py`. До 1920px величины не меняются; снимки 1024–1920 остаются валидными.

## Вне объёма этапа 1

Содержимое карточки и ассистента (состав, поток, сессии, пометки), окно карточки у упоминания, сноски на поле, страница «Ассистент» — этапы 2–6. В этапе 1 ассистент и карточка переносятся в каркас панели без изменения поведения.

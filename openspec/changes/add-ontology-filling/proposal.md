# Proposal

## Why

Модель онтологии без данных ничего не даёт. Основной источник утверждений — извлечение из учебников библиотеки моделью с цитатами, ядро сущностей составляется вручную с подсказками модели, из Wikidata берутся только простые факты ([ontology.md](../../../docs/product/ontology.md), раздел 12). Ошибки извлечения неизбежны, поэтому вместе с наполнением нужна страница проверки (решение О5). Это этап 4 [roadmap.md](../../../docs/product/roadmap.md).

## What Changes

- Ядро сущностей вручную с подсказками модели.
- Импорт простых фактов из Wikidata: даты, места, авторство, учителя.
- Извлечение из нового или изменённого источника по фрагментам глав, структурированный вывод по схеме из реестра, цитаты с привязкой к абзацам.
- Нормализация: привязка к существующим сущностям, создание новых по критерию дробности, поиск дублей.
- Сведение повторов, пересчёт согласия.
- Повышение статуса сгенерированного при появлении подтверждений.
- Страница проверки: очередь по приоритету, подтверждение, правка, отклонение, слияние дублей.

## Capabilities

### New Capabilities

- `ontology-extraction`: наполнение онтологии из библиотеки, ядра и Wikidata.
- `ontology-review`: страница проверки утверждений, сущностей и предложений моделей человеком.

### Modified Capabilities

Нет.

## Impact

- Офлайн-задача наполнения онтологии, внутренняя страница проверки.
- Расходы в бюджете «наполнение»; оценка стоимости на пробной выборке перед полным проходом.
- Зависит от [add-ontology-core](../add-ontology-core/proposal.md), событий [add-source-pipeline](../add-source-pipeline/proposal.md) и сервиса LLM.

# Кейсы: source-quality-followups

Изменение — доработка качества загрузки и поиска по итогам пробной загрузки каталога
(`openspec/changes/archive/2026-11-06-source-catalog/validation.md`). Поведение уже описано
в спецификациях; дельта не заводится (`skip_specs: true`), кроме случаев, где сценарий
спецификации неоднозначен — такие отмечены явно.

## Требования

| REQ | Источник | Формулировка (SHALL) |
|---|---|---|
| R1 | `document-structure` / «Оглавление источника» | Оглавление SHALL строиться по заголовкам текста и по печатному оглавлению, если оно есть; расхождения — предупреждения |
| R2 | `document-structure` / «Склейка абзацев» | Переносы строк внутри абзаца убираются; настоящий дефис остаётся; абзац через страницу — один абзац |
| R3 | `paragraph-search` / «Гибридный поиск», «Деградация» | Смысловая часть поиска при сбое провайдера деградирует, а не роняет запрос; сбой пишется в журнал |
| R4 | `paragraph-indexing` / «Версия модели эмбеддингов» | Вектор хранит модель и версию; при другой модели — свой индекс; поиск переключается на готовый |
| R5 | `paragraph-indexing` / «Только изменённое» | Тот же текст той же моделью — готов; эмбеддинг не пересчитывается |
| R6 | `source-catalog` / «Метаданные с сайта и правки человека» | Год издания SHALL заполняться с сайта, если он там есть; пустое поле — не ошибка |
| R7 | `source-catalog` / «Добавление источника по ссылке» | Источник добавляется по ссылке; недостающие поля — не повод падать |

## Пользовательские сценарии (UC)

| ID | Сценарий | Актор | Предусловия | Шаги | Ожидаемый результат | REQ |
|---|---|---|---|---|---|---|

| UC-2 | Читатель открывает справочную статью | читатель | Статья ЭСБЕ/EB1911 длиннее нескольких абзацев | открыть источник → текст | Несколько абзацев, а не одна простыня | R2 |
| UC-3 | Оператор проверяет карточку книги Gutenberg | оператор | Книга на Gutenberg, у которой год издания есть на Wikidata | `catalog add` → карточка | Год первого издания заполнен (например, 1785) | R6 |

| UC-6 | Оператор смотрит замер индексации | оператор | Боевой провайдер эмбеддингов доступен | запуск замера | Есть числа: скорость на абзац, оценка на библиотеку, расход лимита | R4 |

## Краевые случаи (EC)

| ID | Категория | Ситуация | Ожидаемое поведение | Приоритет |
|---|---|---|---|---|
| EC-1 | Пустые данные | PDF с пустым оглавлением (`toc` пуст) | Прежнее поведение по шрифту, без предупреждений о расхождении | высокий |
| EC-2 | Границы | Закладка на страницу с номером больше числа страниц | Закладка игнорируется, предупреждение | высокий |
| EC-3 | Границы | Две закладки на одну страницу | Обе главы на месте, порядок сохраняется | средний |
| EC-4 | Границы | Статья из одной строки-абзаца | Один абзац, никакого разбиения по точкам | высокий |
| EC-5 | Ошибки | Gutenberg RDF недоступен, когда ищем год | Год `None`, источник добавляется, без падения | высокий |
| EC-6 | Ошибки | Wikidata отвечает ошибкой при поиске года | То же: год `None`, лог-запись | высокий |
| EC-7 | Ошибки | Эмбеддер вернул `None`/пустой вектор | Абзац не помечается готовым, ошибка видны в журнале | средний |
| EC-8 | Повтор | Повторный запуск индексации при том же сбое | Сбой не повторяется бесконечно: задача завершается ошибкой | высокий |
| EC-9 | Конкурентность | Две задачи индексации одновременно | Вторая видит незавершённое и не дублирует | средний |
| EC-10 | Локаль | Название книги и автор на языке оригинала (не ru) | Поиск года по оригиналу, без транслитерации | средний |
| EC-11 | Совместимость | Индекс, собранный до изменения | Не требует переиндексации: прежние векторы читаются как есть | высокий |
| EC-12 | Миграция | Существующие записи каталога без года | Не переписываются молча; год появляется при следующем `harvest` | средний |
| EC-13 | Локаль | Кириллица и диакритика в запросе замера | Без искажений в отчёте (UTF-8) | низкий |
| EC-15 | Границы | Длинное тело статьи (сотни предложений) | Один абзац, по точкам не режем | высокий |
| EC-16 | Границы | Закладка PDF указывает на страницу, где заголовка нет, а он есть на другой странице | Предупреждение `toc_mismatch` с обеими страницами, структура по шрифту | средний |
| EC-17 | Данные | Статья подписана подшаблоном `{{ЭСБЕ/Автор\|Имя}}` | Автор найден: подпись позиционным параметром подшаблона | высокий |

## Журнал кейсов

- 2026-11-13: кейсы заведены до кода, по findings из `validation.md` и по требованиям R1–R7.

  смысловой поиск при несовпадении размерности падает с `ValueError` (numpy), а индексация
  с другим эмбеддером — `ValueError: Vector dimension error` (UC-5, TC-10).

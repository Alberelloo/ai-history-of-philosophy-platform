## MODIFIED Requirements

### Requirement: Видимость и публикация

Поиск MUST NOT возвращать абзацы неопубликованных версий, снятых источников, источников вне области видимости запрашивающего и источников, закрытых для региона запроса.

#### Scenario: Снятый источник

- **GIVEN** источник снят с публикации
- **WHEN** запрос совпадает с его абзацем
- **THEN** этого абзаца нет в результатах

#### Scenario: Закрытый для региона источник

- **GIVEN** источник открыт только региону `RU`
- **WHEN** запрос из другого региона совпадает с его абзацем
- **THEN** этого абзаца нет в результатах

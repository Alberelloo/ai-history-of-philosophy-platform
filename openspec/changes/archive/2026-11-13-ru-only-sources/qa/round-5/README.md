## Как воспроизвести

```powershell
cd ai-history-of-philosophy-platform
# Chromium не стартует с системным TMP: каталог внутри репозитория обязателен.
$tmp = (Resolve-Path ".stack\tmp").Path
$env:TMP = $tmp; $env:TEMP = $tmp
$env:PYTHONIOENCODING = "utf-8"

# 1. Команда человека: весь набор без e2e (без TMP браузерные тесты уходят в skipped)
.venv\Scripts\python.exe -m pytest -q -m "not e2e" -p no:cacheprovider

# 2. То же с TMP внутри репозитория — браузерные тесты выполняются
.venv\Scripts\python.exe -m pytest -q -m "not e2e" -p no:cacheprovider

# 3. Целевые кейсы групп 1, 3, 5, 6 подробно
.venv\Scripts\python.exe -m pytest -v -p no:cacheprovider tests\knowledge\test_regions.py tests\knowledge\test_service.py::test_assistant_context_without_closed_source_paragraph tests\assistant\test_regional_access.py tests\library\test_regions.py tests\gateway\test_region.py

# 4. Независимый живой стенд (dev_stack + свои источники + HTTP + Playwright)
.venv\Scripts\python.exe openspec\changes\ru-only-sources\qa\round-5\harness\live_checks.py
```

## Стенд

`scripts/dev_stack.py` в-process без демо-источников: сервисы LLM, библиотека, поиск, ассистент,
знания, worker и шлюз (запасной регион `RU`). Тестировщик добавил два источника через настоящий
конвейер библиотеки: открытый сборник (вид без регионов) и «Закрытый учебник [RU]» (вид с
`regions: ["RU"]`). Онтология и упоминания посеяны теми же классами, что `scripts/seed_demo.py`
(сущность «Гуссерль», утверждение `influenced_by` с цитатой из закрытого абзаца и отдельное — из
открытого; упоминания в обоих абзацах). Второй шлюз запущен с `PHILOGRAPH_REGION_HEADER=CF-IPCountry`
и `PHILOGRAPH_TRUSTED_PROXY=1`: регион приходит заголовком страны от «CDN», как в проде.

## Что проверено на живом стенде

- **Карточка (UC-20, TC-41/TC-42, EC-38/EC-39).** Для DE утверждение «Гуссерль → Брентано»
  остаётся со `status: "sourced"`, `label: "Брентано"`, но `evidence: []`, `attributed_to: []`,
  `attributions: []`; подтверждение открытого источника остаётся. Для РФ — цитата и ссылка
  `/p/<id>` закрытого источника на месте, «где читать» по обоим источникам.
- **Граф (UC-21, TC-43, TC-55).** Сырой `/v1/graph` и `POST /v1/graph/build` через шлюз: у связи
  закрытого источника пустые `evidence`/`attributions`, статус `sourced`, узлы те же, что у РФ.
  Для РФ подтверждение на месте.
- **«Где читать» и упоминания (UC-22, TC-44).** DE: только открытый источник и только открытый
  абзац в `/v1/mentions`; РФ: оба.
- **Сырые утверждения (TC-55).** `/v1/entities/{id}/statements` через шлюз для DE — без цитат и
  атрибуций закрытого источника; для РФ — с ними; открытое подтверждение не задето.
- **Контекст ассистента (UC-23, TC-45, TC-49).** `region: DE` в теле: в `paragraphs` нет абзаца
  закрытого источника, `sources` без него; `region: RU` — абзац есть.
- **Ассистент (UC-24…UC-27, TC-47/48/49/50/51/52/54).** Регион из заголовка доходит до поиска:
  в промпте основной модели у DE нет текста закрытого источника и нет ссылок на него, у РФ —
  есть. Без заголовка, с `XX` и `T1` — как неизвестный регион; `ru` — как РФ. Выделение из
  закрытого источника и `scope=current` + `source_id` закрытого источника для DE: текста нет в
  промпте, ответ помечен «без опоры на библиотеку».
- **Второй слой проверки ссылок (TC-53).** Отдельный экземпляр LLM с подставным ответом,
  ссылающимся на `[99]`: ссылка удалена, фрагмент неподтверждён, в журнале
  `assistant.citation.invented`.
- **Безопасный отказ (TC-46, EC-41).** Убитая библиотека: карточка и `internal/assistant/context`
  отвечают 503 `knowledge_unavailable`; ассистент при этом отвечает по поиску, в журнале
  `assistant.ontology.skipped reason=knowledge_unavailable`. Убитый поиск — `unavailable`
  `search_unavailable`.
- **Регион не запоминается (EC-37/EC-42/EC-43).** Запросы DE → RU → DE и повтор вопроса дают
  результат своего региона каждый раз.
- **Браузер.** Читатель из РФ: карточка с двумя ссылками `/p/` (закрытый и открытый абзацы) и
  «где читать» по обоим источникам. Читатель из DE: строка «Брентано» без ссылок и атрибуции,
  открытое подтверждение со ссылкой, «где читать» только открытый источник. Ошибок консоли и
  сетевых сбоев нет.

## Осталось непроверенным

- `tests/e2e` (93 deselected): нужен собранный `web/dist` и подъём стека; браузерные сценарии
  проверены через `web/dist` на живом стенде, но не сквозными тестами.
- Настоящий CDN и проверка конфигурации развёртывания — задача 8.6 (вне групп 3–6).
- EC-36 (идентификаторы закрытых источников, которых нет среди подтверждений) проверен
  автотестом `test_card_keeps_open_source_confirmation` (закрыт посторонний `s_other`), не живым
  стендом.
- EC-44 с пробелами вокруг кода страны (` ru `) живым HTTP проверить нельзя: HTTP-клиент не
  отправляет значение заголовка с ведущими/замыкающими пробелами (`Illegal header value`).
  Живой прогон использовал `ru`; обрезка пробелов покрыта `tests/gateway/test_region.py` и
  `tests/library/test_regions.py`.
- Интерфейс ассистента в браузере не прокликивался: ответ ассистента проверен по HTTP, событиям
  и промпту модели; карточка проверена в браузере.
- Для TC-53 использован подставной конфиг LLM (`qa/round-5/llm-invented.yaml`), потому что демо-
  модель никогда не ссылается на непереданный абзац. Это данные стенда, не правка продукта.
- Данные онтологии и упоминаний посеяны классами библиотеки/знаний (как `seed_demo.py`), а не
  через интерфейс оператора: проверялось поведение фильтра, а не ввод данных.

# Spec Delta

## Purpose

Делает продукт доступным участникам исследования по публичному адресу и позволяет обновлять его без потери данных и с быстрым откатом.

## ADDED Requirements

### Requirement: Публичный адрес по HTTPS

Продукт SHALL быть доступен по публичному адресу только по HTTPS. Запросы по HTTP SHALL перенаправляться на HTTPS. Сертификат SHALL обновляться автоматически.

#### Scenario: HTTP

- **WHEN** посетитель открывает адрес по HTTP
- **THEN** его перенаправляет на HTTPS

### Requirement: Внутренние части не видны снаружи

Снаружи SHALL быть доступны только веб-клиент и API-шлюз. Базы, очередь, сервис LLM и внутренние интерфейсы сервисов MUST NOT быть доступны из интернета.

#### Scenario: Порт базы

- **WHEN** снаружи проверяются открытые порты сервера
- **THEN** доступны только порты HTTP и HTTPS

### Requirement: Автоматический перезапуск

Упавший сервис SHALL перезапускаться автоматически. Перезапуск SHALL записываться событием.

#### Scenario: Падение

- **WHEN** процесс ассистента падает
- **THEN** он перезапускается, в журнале событие о перезапуске

### Requirement: Обновление с миграциями

Обновление SHALL применять миграции базы автоматически перед запуском новых версий сервисов. Неудачная миграция SHALL останавливать обновление, оставляя прежнюю версию работать.

#### Scenario: Неудачная миграция

- **WHEN** миграция падает при обновлении
- **THEN** работает прежняя версия, оператор видит ошибку

### Requirement: Откат обновления

Оператор SHALL откатывать продукт к прежней версии одной командой. Миграции SHALL писаться так, чтобы прежняя версия кода работала с новой схемой хотя бы до следующего обновления.

#### Scenario: Откат

- **WHEN** после обновления выросла доля ошибок
- **THEN** оператор откатывает одной командой, работает прежняя версия

### Requirement: Версия в журнале

Каждый сервис SHALL сообщать свою версию при старте и в проверке состояния, чтобы по журналу было видно, какая версия обработала запрос.

#### Scenario: Версия

- **WHEN** сервис стартует
- **THEN** в журнале событие старта с версией

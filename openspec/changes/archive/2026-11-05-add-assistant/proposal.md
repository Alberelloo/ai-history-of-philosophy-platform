# Proposal

## Why

Ассистент по выделенному месту и ассистент как база знаний закрывают сценарии С2–С5 из [vision.md](../../../../docs/product/vision.md): помогает понять трудное место, не уходя из текста, и отвечает по нескольким источникам со ссылками. В этом изменении ассистент работает без онтологии и служит базовой линией для измерения её вклада (этап 3 [roadmap.md](../../../../docs/product/roadmap.md)).

## What Changes

- Панель ассистента: вопрос о выделенном фрагменте или общий вопрос, ответ потоком, остановка, новый диалог.
- Память диалога в браузере в пределах окна ассистента.
- Маршрутизация вопроса быстрым вызовом модели по типам: по месту, база знаний, другие авторы, генезис и контекст, вне темы.
- Заданные цепочки шагов для каждого типа без онтологии; шаги онтологии подключит изменение [add-ontology-aware-assistant](../2026-11-05-add-ontology-aware-assistant/proposal.md).
- Ссылки на абзацы в ответе, проверка ссылок и цитат кодом, пофрагментная пометка того, что сказано без опоры на источники.
- Режим «только по источникам» и честный отказ, когда ответа в источниках нет.
- Язык ответа по языку вопроса, понятные сообщения при недоступности модели и исчерпании лимита.

## Capabilities

### New Capabilities

- `assistant-dialog`: как пользователь задаёт вопросы, видит ответ и ведёт диалог.
- `question-routing`: как определяется тип вопроса и выбирается цепочка шагов.
- `answer-grounding`: ссылки на источники, их проверка, пометка неподтверждённого и отказы.

### Modified Capabilities

Нет.

## Impact

- Сервис ассистента, панель ассистента в веб-клиенте, выделение текста на экране чтения.
- Использует поиск ([add-paragraph-search](../2026-11-05-add-paragraph-search/proposal.md)) и сервис LLM ([add-platform-foundation](../2026-11-05-add-platform-foundation/proposal.md)).
- Настройки «генерация без опоры» и «только по источникам» хранятся в браузере ([add-onboarding-and-settings](../2026-11-05-add-onboarding-and-settings/proposal.md)).

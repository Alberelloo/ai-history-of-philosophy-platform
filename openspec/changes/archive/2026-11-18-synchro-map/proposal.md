# Proposal

## Why

Страница графа сегодня строит граф от одной сущности обходом по рецепту (до 60 узлов) и раскладывает узлы «лесенкой» по году — без настоящей оси времени. Читатель не видит, кто чей современник, в какую эпоху написан труд и какие события шли рядом. Владелец прошёл шесть итераций макета «синхронологической карты на столе философа» ([desk.html](../../../docs/design/system/previews/graph-f02-lenses/desk.html), журнал — [design-cycle-log.md](../../../docs/design/features/graph-page-qa/design-cycle-log.md), решения — [graph-desk-scene-direction.md](../../../docs/design/features/graph-desk-scene-direction.md)) и утвердил его как замену страницы графа.

Решения владельца (2026-11-18): заменить GraphPage; расширить онтологию целиком (датировка эпох, вид группы, роли персон, виды событий), чтобы работали все семь фильтров макета; перенести в продукт и лист, и стол.

## What Changes

- **Карта раздела вместо графа от одной сущности.** Ось X — время; страты сверху вниз: События · Эпохи · Люди (ленты жизни, упаковка по дорожкам) · Труды и идеи (значок на году с подписью-«булавкой»). Линзы сворачивают страты. Карта вписывается в высоту окна; при нехватке места дорожки людей прокручиваются внутри карты.
- **Выбор любой сущности** (персона, труд или идея, событие, эпоха, направление или школа): цвет = принадлежность (выбранный и его труды, учителя, ученики; для группы — до шести участников своими цветами), нерелевантные труды убираются, люди приглушаются, но читаются и выбираются. Линии — только влияния между людьми; достроенные моделью — пунктиром. Нажатие на линию — подробности связи.
- **Правая сворачиваемая панель:** поиск по карте, «Выбрано» (с расшифровкой цветов и действием «Достроить связи»), фильтры столбиком (время, направление, школа, роль, вид сущности, вид события, только проверенные), условные знаки. Свёрнутая — рельс со значками.
- **Окно времени** на обзорной шкале под осью; при узком окне карта приближается.
- **Достройка сохраняется:** для выбранной сущности «Достроить связи» запускает прежний поток `/graph/build` по подходящему рецепту; новые связи появляются на карте пунктиром.
- **Новый эндпоинт** `GET /api/knowledge/v1/map`: сущности раздела с интервалами дат, группы с участниками и видом, связи (влияние, авторство, членство, участие) со статусом и `in_textbook`.
- **Онтология:** датировка эпох; значения-свойства «вид группы», «роль персоны», «вид события» (значения из списка); роли персон из Wikidata (P106).
- **Сцена «стол философа»:** лист с картой на столе (предметы вокруг листа), день и вечер при лампе для светлой и тёмной темы; палитра сцены — токены.
- Адрес: `/graph` — карта раздела; `/graph/<id>` — карта с выбранной сущностью (старые ссылки из карточек продолжают работать); состояние фильтров и выбора — в параметрах адреса.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `knowledge-graph`: изменены «Запрос графа», «Показ графа», «Ограничение размера», «Пустой граф», «Подробности связи», «Пометка достроенного»; добавлены «Карта раздела», «Выбор на карте», «Фильтры и поиск карты», «Панель карты», «Линзы и окно времени».
- `ontology-registry`: изменено «Типы сущностей в реестре» (датировка эпохи, значения-свойства из списка); добавлено «Виды групп, роли персон и виды событий».
- `visual-design`: добавлено «Сцена карты»; изменено «Раскладка без наложений» (карта и панель на 1024–1920, кадр 16:9).

## Impact

- Сервис знаний: `src/philograph/knowledge/registry_data.py` (новые значения-свойства, `dating` для `epoch`), проверка значений из списка в `statements.py`, новый модуль карты рядом с `graph.py`, маршрут в `app.py`, заполнение ролей в `filling.py`; шлюз — лимит для `/map`.
- Веб-клиент: `GraphPage.tsx` заменяется картой (`web/src/map/…`), `App.tsx` (маршрут, параметры), `ui.tsx` (значки), каталоги строк RU/EN и `ontology.*.json`, `styles.css` / новый `styles/map.css`, ассеты сцены, `docs/design/tokens.json` → `tokens.css`.
- Тесты: сервис (`tests/knowledge/test_map.py`, реестр), UI (`tests/web/test_map.py`), сквозные (`tests/e2e/test_site.py` — граф из карточки), визуальные эталоны графа пересоздаются; прослеживаемость новых и изменённых требований.
- Демо-данные: эпохи, события, группы и роли в `scripts/seed_demo.py`, чтобы карта была не пустой в e2e.
- Документы: `graph-page-design.md` (ссылка на этот change как на реализацию), README макета.

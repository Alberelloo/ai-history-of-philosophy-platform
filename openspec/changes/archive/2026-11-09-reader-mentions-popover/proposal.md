# Proposal

## Why

Упоминания сейчас — `<button>` со сплошным подчёркиванием, окно карточки открывается щелчком по координатам указателя и перекрывает колонку текста. Владелец утвердил (reader-panels.md v1.2, Р5): окно карточки открывается только щелчком или Enter/Space, наведение ничего не открывает; окно компактное (имя, годы, до двух утверждений, «Открыть карточку»), встаёт на поле справа (K1) или под строкой (K2–K4) и не закрывает строку упоминания; полная карточка — в правой панели. Подчёркивание — цвет семьи сущности; когда сервер ещё не отдаёт тип, подчёркивание нейтральное.

Это второй этап документа (раздел 16). Он делает упоминания и окно карточки такими, как описано; полная карточка в панели — этап 3.

## What Changes

- Сервер: `/api/knowledge/v1/mentions` отдаёт `entity_type` у каждого упоминания (N1); `/entities/{id}/card` отвечает 404 `entity_not_found` на неизвестную сущность (N2, сейчас `Entities.get` падает на `.one()` и отдаёт 500).
- Упоминание — `span role="button" tabindex="0"` (не `<button>`: в Firefox текст внутри `button` нельзя выделить), подчёркивание цветом семьи на 65%, фон наведения — `*-tint`; без типа — нейтральный `ink-2`.
- Настройка вида упоминаний «Подчёркивать / При наведении» (поле `mentions: "underline" | "hover"` в хранилище формата 3).
- Окно карточки только по щелчку/Enter/Space; положение по 4.3; состав по 4.4 (до двух утверждений, без переключателей источников, «Открыть карточку» и первый рецепт графа); стек «Назад» в окне; загрузка/ошибки по 4.7.
- Кэш ответов карточек в памяти вкладки (до 50, по ключу `id + onlyTextbook + generation`), отмена запросов `AbortController`.
- Правка `docs/design/system/components/Popover.md`: до двух утверждений, без переключателей, открытие только щелчком.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `entity-mentions`: «Показ при чтении» — цвет семьи, вид упоминаний по настройке.
- `entity-cards`: «Карточка рядом с текстом» — компактное окно у упоминания, открывается только щелчком; полная карточка — в правой панели.
- `reader-settings`: «Набор настроек» — вид упоминаний.

## Impact

- Сервер знаний: `mentions.for_targets` (поле `entity_type`), `Entities.get` (404 `entity_not_found`).
- Клиент: `ReaderPage.tsx` (упоминания `span[role=button]`, цвет семьи), `CardPopup.tsx` (положение, состав, стек, загрузка/ошибки), `storage.ts` (поле `mentions`), `SettingsPage.tsx` (настройка вида), `ui.tsx` (`familyOf`), `styles.css`/`components.css`.
- Тесты: T6–T11, T15; прослеживаемость; снимки S1/S2/S3/S3a.
- Документ дизайна: `components/Popover.md`.

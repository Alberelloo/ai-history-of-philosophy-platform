## MODIFIED Requirements

### Requirement: Набор настроек

Настройки SHALL включать: генерация без опоры (по умолчанию включена), только по источникам (по умолчанию выключено), переключатель источников (по умолчанию «все источники»), вид упоминаний (по умолчанию «подчёркивать»). Настройки SHALL действовать сразу, без перезагрузки. Экран настроек SHALL делиться на разделы: внешний вид, ответы ассистента, источники ответов, открытые книги, о проекте, данные. Слева SHALL быть закреплённое оглавление разделов: переход по нему ведёт к разделу, у каждого раздела свой адрес, а пункт раздела, который сейчас виден, отмечен.

#### Scenario: Значения по умолчанию

- **WHEN** посетитель впервые открывает настройки
- **THEN** генерация включена, «только по источникам» выключено, выбраны все источники, упоминания «подчёркивать»

#### Scenario: Переход по оглавлению

- **WHEN** посетитель выбирает в оглавлении настроек раздел «Данные»
- **THEN** экран прокручивается к этому разделу, адрес — `/settings#data`, пункт «Данные» в оглавлении отмечен

#### Scenario: Адрес раздела

- **WHEN** посетитель открывает адрес `/settings#books`
- **THEN** экран настроек открывается на разделе «Открытые книги»

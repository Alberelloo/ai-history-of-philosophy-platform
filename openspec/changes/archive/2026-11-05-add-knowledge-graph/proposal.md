# Proposal

## Why

Сценарий С6: увидеть, как возникла идея, кто на неё повлиял и во что она превратилась. Граф строится по запросу из сохранённых утверждений, а недостающее достраивает модель с явной пометкой (решение А5). Переключатель «только выбранный учебник / все источники» показывает, как тему излагает мой учебник по сравнению с другими (С5, решение О5). Это этап 5 [roadmap.md](../../../../docs/product/roadmap.md).

## What Changes

- Граф по запросу: сущность, рецепт, направление, глубина; сохранённые связи сразу, достроенные моделью по мере появления.
- Достройка только типами рецепта, с проверками целостности, отказом от повторов отклонённого, отложенным сохранением со статусом «сгенерировано».
- Показ графа: узлы по типам, связи по типам и статусам, порядок по времени, подробности связи с атрибуцией и подтверждениями.
- Переключатель источников для графа, карточек и ассистента.

## Capabilities

### New Capabilities

- `knowledge-graph`: построение и показ графа по запросу с достройкой.
- `source-scope`: переключатель «только выбранный учебник / все источники».

### Modified Capabilities

Нет.

## Impact

- Сервис знаний: обход по рецептам и достройка через сервис LLM; очередь для отложенной записи.
- Веб-клиент: экран графа, переключатель источников.
- Расходы на достройку в бюджете «сайт» с дневным лимитом.

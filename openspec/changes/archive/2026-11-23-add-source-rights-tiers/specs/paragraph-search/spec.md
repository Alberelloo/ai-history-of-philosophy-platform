## MODIFIED Requirements

### Requirement: Видимость и публикация

Поиск MUST NOT возвращать абзацы неопубликованных версий, снятых источников, источников вне области видимости запрашивающего, источников, закрытых для региона запроса, и источников без права показа (правовой статус `in_copyright` или `unknown`). Абзацы таких источников SHALL оставаться доступными только внутренним интерфейсам (например, сервису знаний для извлечения), но не читателю.

#### Scenario: Снятый источник

- **GIVEN** источник снят с публикации
- **WHEN** запрос совпадает с его абзацем
- **THEN** этого абзаца нет в результатах

#### Scenario: Закрытый для региона источник

- **GIVEN** источник открыт только региону `RU`
- **WHEN** запрос из другого региона совпадает с его абзацем
- **THEN** этого абзаца нет в результатах

#### Scenario: Источник под охраной

- **GIVEN** источник со статусом `in_copyright` обработан для онтологии
- **WHEN** читатель ищет совпадающий с его абзацем текст
- **THEN** абзацев этого источника нет в результатах

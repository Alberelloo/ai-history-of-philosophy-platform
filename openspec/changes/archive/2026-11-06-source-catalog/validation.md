# Пробная загрузка каталога: итоги

Дата: 2026-11-06. Каталог `sources/catalog.yaml`: 36 записей. Одобрено 35, одна отклонена: «ЭСБЕ/Познание» — перенаправление без текста. Записи нашёл агент поиска, отчёт в `sources/discovery-report.md`.

Одобрил их ведущий (Claude) для проверки работоспособности, по разрешению владельца. Перед настоящим запуском каталог пересматривается. Особенно это касается вида лицензии `pd-site` (общественное достояние по отметке сайта) и правила 70 лет.

## Как проверяли

1. **Четыре книги**, по одной с каждого вида сайтов: Gutenberg, Wikisource en, Wikisource ru, archive.org. Синхронизация шла во временную базу, затем смотрели структуру.
2. **Весь каталог на стенде разработки** (`scripts/dev_stack.py`, все сервисы). Скрипт проверки:
   - `sync` дважды;
   - `status`;
   - для каждого источника: оглавление и первая глава через API, открытие в читалке (Playwright, снимок), поиск по слову из абзаца;
   - ошибки в журналах сервисов.
3. **Повторная загрузка после исправлений** во временную базу, затем ещё одна синхронизация после смены версии конвейера на 2. Так проверялось обновление уже опубликованных источников.

## Что осталось открытым

1. **Структура PDF-учебников.** У OpenStax заголовки определяются по размеру шрифта, и главами становятся крупные номера («2», «3», «12»). В цифровых PDF есть оглавление-закладки (`get_toc`), по нему структура была бы точной. Это следующая доработка извлечения, важная для учебников.
2. **Сканы archive.org.** Weber (проба из четырёх книг) с текстовым слоем после распознавания: строки оглавления становятся заголовками, структура почти не читается. Правило подбора: Gutenberg, Wikisource и цифровые учебники; archive.org — только если других вариантов нет.
3. **Смысловой поиск на стенде разработки.** В журналах `search.semantic.unavailable` (`ValueError`) на части запросов. Векторный индекс по сохранённой базе ищет без ошибок, значит, сбой на эмбеддинге запроса во время массовой индексации. Нужно отдельно разобрать в сервисе поиска; поиск по словам работает.
4. **Скорость индексации** на стенде разработки около 150 мс на абзац (см. «Итог»). Нужен замер на настоящем провайдере.
5. **Короткие справочные статьи** (ЭСБЕ, EB1911): 1–3 блока, статья целиком одним абзацем. Источник так и свёрстан, но для справочника нужна разбивка.
6. **Адаптеры:** gutenberg не знает года издания; wikisource не извлекает авторов со страниц без шаблона «Отексте» или `header`. Обходится правками `override` в каталоге.
7. **press.rebus.community** отвечает 403 на User-Agent проекта. Источник пропущен: подменять User-Agent нельзя.
8. **Онтология и упоминания** без ключа настоящей модели не проверялись: демо-модель не отдаёт JSON, извлечение повторяет запросы впустую.

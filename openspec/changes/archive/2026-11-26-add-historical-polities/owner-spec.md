# Спека: историческая политическая карта на глобусе (Cliopatria)

Статус: **в очереди** — запускать после приёмки переработки онтологии (`philo`).
Исполнитель — Claude, полный цикл: прораб (умная модель) + субагенты по ролям. Вариант 1 (любой год).

## 1. Зачем

Глобус показывает философов и связи **во времени**: есть ползунок года. Но подложка — **современная**
политическая карта (`countries-110m`). На 1650 году это анахронизм: показываются границы XXI века.
Нужна политическая карта, **актуальная на выбранный год T** (Священная Римская империя, Речь
Посполитая, Османская империя и т. п.).

## 2. Данные

**Cliopatria** (Seshat Global History Databank), лицензия **CC BY 4.0**:
- `cliopatria.geojson` (~14K записей, 1600+ политических образований, 3400 BCE – 2024 CE).
- Поля: `Name`, `geometry` (EPSG:4326), `Area`, `Type` (POLITY/RELATION), **`FromYear`–`ToYear`**, `Wikipedia`, **`Wikidata`**, `SeshatID`.
- Любой год T: строки, где `FromYear ≤ T ≤ ToYear`.
- Ограничение (сами авторы): границы приблизительны и спорны — карта «одной из версий», не истина.

Источник: https://github.com/Seshat-Global-History-Databank/cliopatria , https://zenodo.org/records/13363121

## 3. Архитектура (предложение — уточнить в design.md)

1. **Шаг сборки (build)**: скрипт читает `cliopatria.geojson`, упрощает полигоны (Дуглас–Пекер или
   до ~1:110m), строит индекс по годам, пишет компактный артефакт (SQLite/JSON, не в git).
   Запускается один раз / при обновлении датасета. В git — только скрипт и метаданные, не данные.
2. **Сервис знаний**: эндпоинт `GET /v1/map/polities?year=T` → образования, активные на T
   (id, русское название, упрощённая геометрия, Wikidata, статус). Кэш по годам (LRU).
3. **Клиент (глобус)**: при смене года подгружает слой политик T и рисует границы + названия
   вместо/поверх современной карты; медальоны философов и связи — без изменений; названия не
   перекрывают медальоны и UI.
4. **Названия**: русские из Wikidata (`Wikidata`-id → метка `ru`), при отсутствии — английское
   с пометкой «без русского названия». Никаких выдуманных переводов.

## 4. Требования

### Requirement: Загрузка и подготовка исторических границ

Система SHALL готовить данные Cliopatria шагом сборки: упрощать геометрию до размера, пригодного
для передачи в браузер, и индексировать записи по диапазону `FromYear`–`ToYear`. Данные Cliopatria
SHALL храниться вне git; в репозитории — скрипт сборки, версия датасета и лицензия (CC BY 4.0).

#### Scenario: сборка
- **WHEN** запущен скрипт сборки на `cliopatria.geojson`
- **THEN** создан артефакт с упрощёнными полигонами и индексом по годам; размер слоя одного года
  после gzip ≤ 500 КБ на типичный кадр

### Requirement: Эндпоинт слоя на год

Сервис знаний SHALL отдавать `GET /v1/map/polities?year=T` — список политических образований,
активных на год T (`FromYear ≤ T ≤ ToYear`), каждое: идентификатор, название (RU), геометрия
(упрощённая), Wikidata-id (или null), статус. Ответ SHALL кэшироваться по году и повторяться без
пересчёта.

#### Scenario: год 1650
- **WHEN** запрошен `?year=1650`
- **THEN** в ответе образования, активные на 1650; в геометрии нет государств, возникших позже

#### Scenario: пустой год
- **WHEN** на год T активных образований нет
- **THEN** ответ 200 с пустым списком (без ошибки), клиент показывает только подписи эпох/философов

### Requirement: Рендер на глобусе

Глобус SHALL рисовать границы политических образований на выбранный год T и их названия по-русски;
подписи SHALL не перекрывать медальоны философов, подпись источника и элементы управления.

#### Scenario: смена года
- **WHEN** ползунок года перемещён с 1650 на 1800
- **THEN** границы и подписи заменяются на актуальные для 1800 без перезагрузки страницы

### Requirement: Русские названия

Названия политических образований SHALL быть на русском языке (метка Wikidata `ru` по `Wikidata`-id).
При отсутствии русского названия SHALL показываться оригинальное с пометкой. Переводы MUST NOT
выдумываться моделью.

#### Scenario: Священная Римская империя
- **WHEN** на год 1650 активно образование с Wikidata-id Священной Римской империи
- **THEN** подпись — «Священная Римская империя» (русская метка Wikidata)

### Requirement: Лицензия и атрибуция

Данные Cliopatria SHALL использоваться с атрибуцией CC BY 4.0 (имя авторов, ссылка, версия) на
странице карты и в документации.

## 5. Приёмочные критерии (инварианты)

| # | Критерий | Порог |
|---|---|---|
| H1 | Активность: для каждого образования `FromYear ≤ T ≤ ToYear` | 100% |
| H2 | Размер слоя одного года (gzip) | ≤ 500 КБ |
| H3 | Русские названия | ≥ 90% (остальные — с пометкой) |
| H4 | Границы меняются при смене года (набор ≠ на разных T) | да |
| H5 | Подписи не перекрывают медальоны/UI (на 1024×576) | 0 наложений |
| H6 | Загрузка слоя года | ≤ 1 с на локальном стенде |
| H7 | Атрибуция CC BY 4.0 видна | да |
| H8 | `lint-imports`, traceability, `ruff` | чисто |
| H9 | Данные Cliopatria не в git; в репозитории — скрипт/метаданные | да |

## 6. Ограничения

- Данные — CC BY 4.0; атрибуция обязательна.
- Объём 49 МБ — только через шаг сборки; в браузер — упрощённый слой.
- Историческая точность: границы приблизительны (риск не «данных», а интерпретации); SHALL быть
  пометка на карте, что карта отражает одну из версий границ.
- Не трогать runtime-файлы Lead'а; ветка от `claude/embedding-docker`.
- Соблюдать `docs/process/*`, роли, вердикт судьи.

## 7. Процесс и очередь

- **Очередь**: запускать после приёмки онтологии — сервер у Claude 1 CPU / 1.9 ГБ, параллельно с
  онтологией не потянет сборку/тесты.
- Полный OpenSpec-цикл: proposal → specs (дельты выше) → design.md («Выбор решения»: упрощение,
  кэш, формат артефакта, рендер) → tasks.md → реализация → тесты-инварианты (H1–H9) → судья.
- Пайплайн: прораб (умная модель) + субагенты (coder, tester, reviewer, judge).

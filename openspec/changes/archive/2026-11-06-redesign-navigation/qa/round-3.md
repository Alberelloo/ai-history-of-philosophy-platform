## 4. Расхождения

Важность: блокирует / заметно / мелочь.

**D1 (блокирует). Фильтры по нескольким значениям возвращают неверный список**
- Экран: библиотека, фильтр «Вид» (и «Язык» тем же путём). Тема: светлая (проверено по API, поведение не зависит от темы). Язык: RU. Ширина: 1440.
- Ожидалось: `openspec/changes/redesign-navigation/specs/source-library/spec.md`, «Фильтр по виду источника»: «Выбрать все и снять все»: «сначала отмечены все виды, затем ни одного, и в обоих случаях в списке источники всех видов»; «Несколько видов»: учебник и первоисточник → в списке обе книги. «Фильтр по языку»: выбор нескольких языков.
- Получилось: после «Выбрать все» счётчик «· 3», в списке 0 источников, текст «Подходящих источников нет.». Запрос `GET /api/v1/sources?kind=textbook&kind=primary` возвращает один источник (первоисточник), а не два. Запрос с тремя значениями возвращает 0. Причина: шлюз передаёт параметры в библиотеку через `params=request.query_params` (`src/philograph/gateway/app.py:168`); httpx оставляет только последнее значение повторяющегося параметра. Сервер (`src/philograph/library/reading.py:128`) логику видов понимает правильно. Строка в шлюзе есть в `main` (коммит 2a9d35b), то есть дефект давний; новая вёрстка фильтра сделала мультивыбор обычным действием.
- Снимок: `qa/round-3/bug-filter-select-all-1440.png`. Снимок шагов фильтра: `qa/round-3/lib-filter-kind-light-ru-1440.png` (до выбора).

**D2 (заметно). Название книги в боковой панели обрезано**
- Экран: чтение, панель раскрыта (наведение) при 1024 или закреплена при 1440. Тема: светлая и тёмная. Язык: RU и EN. Ширина: 1024 и 1440.
- Ожидалось: `specs/visual-design/spec.md`, «Боковая панель навигации», сценарий «Навигация читается»: «пункты панели разделены промежутками, ни один не перекрывает другой, подписи не обрезаны». `docs/design/system/components/Sidebar.md`: название «шрифтом интерфейса до двух строк (без многоточия по ширине)».
- Получилось: «Теория познания: демонстрационный учебник» занимает три строки, третья скрыта с многоточием (`-webkit-line-clamp: 2`, `scrollHeight` 54px при высоте 36px). Документы расходятся: Sidebar.md допускает две строки, сценарий требует не обрезать. Решение за ведущим.

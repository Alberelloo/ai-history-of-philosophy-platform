## MODIFIED Requirements

### Requirement: Набор настроек

Настройки SHALL включать: генерация без опоры (по умолчанию включена), только по источникам (по умолчанию выключено), переключатель источников (по умолчанию «все источники»). Настройки SHALL действовать сразу, без перезагрузки. Экран настроек SHALL делиться на разделы: внешний вид, ответы ассистента, источники ответов, открытые книги, о проекте, данные. Слева SHALL быть закреплённое оглавление разделов: переход по нему ведёт к разделу, у каждого раздела свой адрес, а пункт раздела, который сейчас виден, отмечен.

#### Scenario: Значения по умолчанию

- **WHEN** посетитель впервые открывает настройки
- **THEN** генерация включена, «только по источникам» выключено, выбраны все источники

#### Scenario: Переход по оглавлению

- **WHEN** посетитель выбирает в оглавлении настроек раздел «Данные»
- **THEN** экран прокручивается к этому разделу, адрес — `/settings#data`, пункт «Данные» в оглавлении отмечен

#### Scenario: Адрес раздела

- **WHEN** посетитель открывает адрес `/settings#books`
- **THEN** экран настроек открывается на разделе «Открытые книги»

### Requirement: Единое хранилище в браузере

Настройки и состояние (выбранный источник, открытые книги, места чтения, закрепление боковой панели, диалоги, отметка об уведомлении) SHALL храниться в одном хранилище браузера с версией формата. При новой версии формата старые данные SHALL переноситься, а непереносимые — сбрасываться к значениям по умолчанию без ошибки.

#### Scenario: Новая версия формата

- **WHEN** клиент обновился, и формат хранилища изменился
- **THEN** настройки и места чтения перенесены, продукт работает без ошибок

#### Scenario: Выбранный источник становится открытой книгой

- **GIVEN** в хранилище прежнего формата запомнен выбранный источник
- **WHEN** клиент переносит данные в новый формат
- **THEN** этот источник — первая открытая книга и текущий источник

#### Scenario: Испорченные данные

- **WHEN** данные в хранилище повреждены
- **THEN** они сбрасываются к значениям по умолчанию, продукт открывается

### Requirement: Сброс данных

В настройках SHALL быть сброс всех данных браузера: настроек, открытых книг, мест чтения, диалогов. Сброс SHALL стоять отдельным блоком «Опасная зона» в конце раздела данных. Перед сбросом SHALL запрашиваться подтверждение.

#### Scenario: Сброс

- **WHEN** посетитель подтверждает сброс
- **THEN** все данные продукта в браузере удалены, при следующем входе снова показывается уведомление

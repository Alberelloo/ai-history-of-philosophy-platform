# Кейсы: reader-assistant

Источник задания: [docs/design/features/reader-panels.md](../../../../../docs/design/features/reader-panels.md), этап 4 (разделы 5.2–5.9, 7, 12.3). Кейсы T17–T27, T35, T38–T40, T44, T48 — из раздела 14.2. T18 (панель действий над выделением) — в `ReaderPage.tsx`, ведёт lead.

## Требования

| REQ | Источник | Формулировка (SHALL) |
| --- | --- | --- |
| R1 | assistant-dialog «Память диалога» | У каждой книги и раздела «Ассистент» SHALL быть свой набор сессий; смена книги — смена набора |
| R2 | assistant-dialog «Память диалога» | Сессии SHALL создаваться, переименовываться и удаляться с подтверждением; пустая не плодится |
| R3 | assistant-dialog «Ход ответа» | Пока идёт ответ, SHALL показываться стадия словами, её номер и время; без процента и счётчика слов |
| R4 | assistant-dialog «Недоступность и лимиты» | Если от сервера нет событий 45 с, клиент SHALL отменять запрос и сообщать об ошибке |
| R5 | reader-settings «Предел объёма диалогов» | Диалоги SHALL вытесняться по порядку из 5.8 при превышении объёма |

## Пользовательские сценарии (UC)

| ID | Сценарий | Актор | Шаги | Ожидаемый результат | REQ |
| --- | --- | --- | --- | --- | --- |
| UC-1 | Диалоги книг не смешиваются | Читатель | Вопрос в A, открыть B, вопрос в B, вернуться в A | В B пустая история до вопроса; в A — только обмены A | R1 |
| UC-2 | Сессии | Читатель | Вопрос 1, «+», вопрос 2; переключение; «+» при пустой | Две сессии; переключение показывает свою историю; «+» не создаёт третью | R2 |
| UC-3 | Переименование/удаление | Читатель | Переименовать (Enter), Esc, пустое имя; удалить с подтверждением | Название сохраняется; Esc отменяет; удалённая сессия исчезает | R2 |
| UC-4 | Стадии ответа | Читатель | Вопрос, сервер шлёт stage/fragment/done | Подписи стадий по порядку, номер «N из 4», время растёт | R3 |
| UC-5 | Тайм-аут | Читатель | Сервер молчит 45 с | Запрос отменён, сообщение об ошибке, «Повторить» | R4 |
| UC-6 | Вытеснение | Читатель | Объём диалогов выше предела | Сессии удаляются по порядку из 5.8 | R5 |

## Тест-кейсы (TC)

| ID | UC | Шаги проверки | Ожидаемый результат | Автотест |
| --- | --- | --- | --- | --- |
| TC-1 | UC-1 | Вопрос в A, B, вернуться, закрыть/открыть A, две вкладки | В B пусто; в A только A; `dialogs[A]`/`dialogs[B]` разные; вкладки не перезаписали чужую книгу | T38 |
| TC-2 | UC-2 | Две сессии, переключение, «+» при пустой, перезагрузка | Названия по первой фразе; «+» не плодит; ответ дописывается в свою сессию; перезагрузка сохраняет | T47 |
| TC-3 | UC-3 | Переименование Enter/Esc/пустое; удаление подтверждение/отмена | Название сохраняется/отменяется; `updatedAt` не меняется; удалённой сессии нет | T48 |
| TC-4 | UC-4 | `route`: stage → пауза → composing → fragments → done; без stage; error | Стадии по порядку; без процента; без stage — «Разбираем вопрос» до фрагмента | T44 |
| TC-5 | UC-5 | `route` без событий 46 с (часы Playwright) | Запрос отменён, сообщение об ошибке | T24 |
| TC-6 | UC-4 | `prefers-reduced-motion: reduce` | Цикл индикатора выключен, подписи меняются по событиям | T35 |
| TC-7 | UC-1 | Поток в A, переход по ссылке ответа в B | Панель показывает B, «Вы пришли из диалога по книге A», «Вернуться»; `/ask` не отменялся | T39 |
| TC-8 | R5 | `philograph:v3` с двумя диалогами; открыть приложение | `philograph:v4` есть, v3 нет; `libraryDialogs` — две сессии; `dialogs` = `{}` | T40 |

## Краевые случаи (EC)

| ID | Категория | Ситуация | Ожидаемое поведение | Приоритет |
| --- | --- | --- | --- | --- |
| EC-1 | Пустые данные | Пустая активная сессия, «+» | Не создаёт новую, фокус в поле вопроса | Высокий |
| EC-2 | Пустые данные | Переключение с пустой сессии без названия | Пустая сессия удаляется сама | Высокий |
| EC-3 | Пустые данные | Переименование в пустое/пробелы | Сохраняется название по первой фразе | Средний |
| EC-4 | Ошибки | Поток оборвался (error/сеть) | Полученная часть с пометками, «Повторить» | Высокий |
| EC-5 | Повтор/конкурентность | Две сессии отвечают одновременно | Потоки не мешают друг другу, оба дописываются | Высокий |
| EC-6 | Повтор | Удаление сессии с идущим ответом | Подтверждение «Ответ ещё идёт», поток отменён | Высокий |

| EC-8 | Миграция | Хранилище формата 3 повреждено | Сброс к значениям по умолчанию без ошибки | Высокий |

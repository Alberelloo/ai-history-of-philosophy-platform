# Proposal

## Why

Ассистент сейчас — один общий диалог на все книги, без истории по книгам, без стадий ответа (только «Остановить», которая видна всегда), без времени, без тайм-аута и без панели действий над выделением. Владелец утвердил (reader-panels.md v1.2): у каждой книги свой набор сессий (Р1, Р11), ответ идёт по стадиям с временем и без процента (Р8), остановка — только во время потока, 45-секундный тайм-аут клиента, общие вопросы уходят в раздел «Ассистент» (этап 6).

Это четвёртый этап документа (раздел 16). Он переносит диалоги в формат 4 с наборами сессий, делает поток ответа со стадиями и временем, и готовит клиент к этапу 6.

## What Changes

- Хранилище формата 4: `dialogs` — словарь «книга → набор сессий», новое `libraryDialogs` для раздела «Ассистент»; сессии и обмены с полями `id`, `createdAt`, `updatedAt`, `chapterId`, `handoffId`, `from`, `handoff`; перенос v3→v4 (старый общий диалог — в `libraryDialogs`).
- Набор сессий на книгу (Р1, Р11): список, создание «+» (пустая не плодится), переименование (Enter сохраняет, Esc отменяет), удаление с подтверждением; несколько сессий отвечают одновременно.
- Поток ответа со стадиями (5.3): «Разбираем вопрос» → «Ищем в источниках» → «Составляем ответ» → «Пишем ответ», номер «N из 4», время с отправки, цикл индикатора; «Остановить» только во время потока, «Повторить», тайм-аут 45 с.
- Ссылки и переходы с `pushState` (5.4), пометки (5.5), строка «только по источникам» (5.6), S12 с «Показать уведомление».
- Сервер: N4 (названия источника/главы и начало абзаца в ссылках), N5 (`entity_id` у ссылки на утверждение), N6 (`paragraph_id` у suggestions), N8 (`answer_language` в `done`), N13 (события `stage`).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `assistant-dialog`: добавлены «Панель действий над выделением» и «Ход ответа»; уточнены «Память диалога» (набор сессий на книгу и раздел) и «Недоступность и лимиты» (тайм-аут клиента).
- `reader-settings`: уточнён «Предел объёма диалогов» (порядок вытеснения по книгам).

## Impact

- Клиент: `AssistantPanel.tsx` (сессии, стадии, время, остановка/повтор/тайм-аут), `storage.ts` (формат 4).
- Сервер ассистента: `service.py`, `grounding.py` (N4, N5, N6, N8, N13).
- Тесты: T17–T27, T35, T38–T40, T44, T48; прослеживаемость; снимки S6–S10, S12, стадий.
- Панель действий над выделением (7), «Спросить об абзаце», Alt+Q — в `ReaderPage.tsx`, который ведёт lead (этап 3): дельта спецификации заводится здесь, реализация — вне зоны записи этого изменения.

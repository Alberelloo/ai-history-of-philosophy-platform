# Design

Задание и все величины — в [docs/design/features/reader-panels.md](../../../docs/design/features/reader-panels.md) (этап 4, раздел 16; разделы 5.2–5.9, 7, 12.3). Здесь — решения по коду, которых нет в документе.

## Контекст

Этапы 1–2 готовы: раскладка K1–K4, каркас панели, состояние панели в `App.tsx`, компактное окно карточки. `AssistantPanel` перенесён в каркас панели (этап 1). Хранилище — формат 3 с полем `mentions` (этап 2).

## Хранилище формата 4 (12.3)

`KEY = "philograph:v4"`. `dialogs` становится `Record<sourceId, DialogSet>`, добавляется `libraryDialogs: DialogSet` для раздела «Ассистент». Типы `DialogSet`/`Session`/`Turn` — как в 12.3. Перенос v3→v4: поля, кроме `dialogs`, переносятся как есть; старый общий диалог `dialogs: unknown[][]` разбивается на сессии и уходит в `libraryDialogs` (обмены получают `id`, `createdAt`/`updatedAt` — время переноса).

`trimDialogs` переписывается под словарь с порядком вытеснения из 5.8 и предела 200 000 знаков. `storage.saveDialog`/`newDialog` заменяются на API сессий: чтение набора книги, запись обмена в сессию, создание/переименование/удаление/переключение сессии.

## Сессии в AssistantPanel

Панель хранит активную сессию книги в состоянии и пишет в хранилище при каждом событии потока (по книге, заданной при отправке, — поток дописывается в свою книгу, даже если читатель ушёл). Список сессий — кнопка «Сессии» в шапке, раскрывает список в теле панели; строки с переименованием и удалением с подтверждением. Пустая сессия без вопросов и без заданного названия удаляется сама при переключении.

## Поток и стадии (5.3)

Стадии: «Разбираем вопрос» (с отправки), «Ищем в источниках» (событие `stage searching`), «Составляем ответ» (`stage composing found N`), «Пишем ответ» (первый `fragment`). Одна строка `role="status"` с активной стадией, номером и временем (таймер раз в секунду, один на панель). Индикатор-точка с циклом 1600ms (`dur-wait`), останавливается на `done`/остановке/ошибке/тайм-ауте; при `prefers-reduced-motion` — неподвижна. «Остановить» видна только во время потока, «Повторить» — после остановки/ошибки/тайм-аута.

## Сервер

- N13: в `Assistant.ask` после `route` — `{"type": "stage", "name": "searching"}`; перед потоком модели — `{"type": "stage", "name": "composing", "found": len(passages)}`.
- N4: `Passage` получает `source_title`, `chapter_title`, `paragraph_start` (первые 120 знаков текста); `Fragment.to_json` отдаёт их в ссылках.
- N5: `Passage` получает `entity_id` (для утверждений онтологии); в `to_json` — у ссылки `kind: "statement"`.
- N6: `no_answer.suggestions` — список `{paragraph_id, title}` вместо строк.
- N8: событие `done` включает `answer_language`.

# Tasks

Ветка `claude/historical-polities` (основа — `origin/claude/embedding-docker`). Все требования — в возможности `geo-timeline`, она уже в `enforce`. Пока тестировщик не добавит тесты шести новых требований (6.x), `check_traceability.py` на ветке красный, это ожидаемо.

Ограничения:
- не трогать runtime-файлы Lead'а: `config/llm.yaml`, `scripts/dev_stack.py`, `src/philograph/platform/queue.py`, `src/philograph/knowledge/filling.py`, `sources/catalog.yaml`, `prompts/__init__.py`, а также `compose.yaml` (решение 9 в design.md);
- данные Cliopatria — только в `data/cliopatria/`, в git не попадают;
- сервер: 1 CPU, 1,9 ГБ ОЗУ. Сборку на полном датасете и браузерные тесты не запускать параллельно с другими тяжёлыми прогонами. Браузерные тесты — по одному файлу.

## 6. Тесты по спецификации (тестировщик)

Тесты пишутся по дельте, а не по коду. Маркер `@pytest.mark.req("geo-timeline", "<требование>", scenario=… | invariant=…)`. Каждый тест проверяет вывод и журнал (`events.one/of` или `knowledge.polities.served` по `request_id` ответа, полученного страницей). Тесты не требуют реального архива и сети: фикстура 2.3, Wikidata — `Fetch`-словарь. Браузерные тесты — минимум: один новый файл `tests/web/test_geo_polities.py`, запуск по одному файлу. Атрибуты, которые сообщает код (`data-polity-from`, `data-borders`, `data-area`), сверяются с независимым расчётом в тесте (наивный фильтр фикстуры, d3-geo в странице теста), иначе проверка тавтологична.

- [ ] 6.1 Инфраструктура: фикстурный артефакт собирается в сессии теста из `mini.geojson`, путь передаётся сервису знаний в `tests/web` через `PHILOGRAPH_POLITIES_DB`; режим «503» — путь к несуществующему файлу. Существующие тесты глобуса идут в режиме 503 (запасной) без правок
- [ ] 6.2 «Сборка исторических границ»: все сценарии; инварианты: (а) геометрия валидна, точность, сферическая площадь < 2π у каждого многоугольника; (б) число строк POLITY = число записанных, ни одна не пропала; (в) один `id` на `Name`; (г) детерминированность; (д) данные вне git (H9)
- [ ] 6.3 «Слой политических образований на год»: все сценарии; инварианты: (а) H1 — для каждого года −3500…2100 набор `id` ответа равен набору наивного фильтра фикстуры, у каждого `from ≤ T ≤ to`; (б) для каждого T все годы `valid_from…valid_to` дают тот же набор, а `valid_from − 1` и `valid_to + 1` — другой (или выходят за −9999…9999); (в) порядок детерминирован; (г) событие без названий и геометрии; (д) без сети и модели
- [ ] 6.4 «Русские названия образований»: все сценарии; инвариант: у каждого образования любого ответа либо `name_status="ru"` и `name` — принятая метка `ru` его QID из словаря фикстур, либо `name_status="original"` и `name == original`; враждебные метки
- [ ] 6.5 «Исторические границы на глобусе»: все сценарии; инварианты: (а) H5 — на 3 размерах окна × 2 годах × наборе центров и приближений 0 пересечений `[data-geo-polity]` между собой, с медальонами, значками, подписями персон и `[data-geo-overlay]`, все в кадре, ≤ 24; (б) H4 — набор `id` подписей и `data-polities` различаются на 1650 и 1800; (в) не больше одного запроса `/map/polities` одновременно при проигрывании; (г) пустой слой — 0 границ и 0 подписей стран
- [ ] 6.6 «Атрибуция исторических границ» (H7): все сценарии
- [ ] 6.7 «Пределы исторического слоя»: сценарий «Замер на фикстуре» тестом; «Замер на реальном артефакте» — запись в `verification.md` по результатам 8.x
- [ ] 6.8 MODIFIED-требования: «Вид «Глобус» на карте раздела» (хронология не запрашивает `/map/polities`), «Политическая карта» (`data-map-mode="modern"` в сценарии «Границы и подписи»), «Пределы глобуса» (вес фрагмента без `/map/polities`), «Глобус без WebGL и без сторонних запросов» (только свой адрес в историческом режиме), «Состояния глобуса» (три новых сценария), «Страна места» (подпись источника в обоих режимах)
- [ ] 6.9 Мутационная проверка, не меньше одной мутации на новое требование. Минимальный набор: `<` вместо `≤` в правиле активности; `valid_to` на единицу больше; кэш по году без учёта интервала (`cached` у соседнего года); пропуск `orient`; потеря самого большого кольца; метка `en` как запасная; `languagefallback=1`; подпись образования без проверки пересечения с `[data-geo-overlay]`; рисование устаревшего ответа; два запроса одновременно; версия датасета константой в клиенте.

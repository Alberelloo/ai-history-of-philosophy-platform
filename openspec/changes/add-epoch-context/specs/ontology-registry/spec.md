# ontology-registry — дельта

## MODIFIED Requirements

### Requirement: Виды групп, роли персон и виды событий

Реестр SHALL содержать значения-свойства из списка: вид группы (школа, направление, институция, кружок), роль персоны (философ, учёный, писатель, богослов, правитель, переводчик; у персоны может быть несколько ролей), вид события (политическое, экономическое, социальное, научное, религиозное, интеллектуальное, биографическое). Значение вне списка SHALL отклоняться. Новые значения списка SHALL дозагружаться в уже заполненный реестр без потери существующих утверждений и без перезаписи изменённого оператором. Роли персон SHALL заполняться из Wikidata (род занятий) по таблице соответствия; не найденное в таблице MUST NOT записываться.

#### Scenario: Вид группы

- **WHEN** для группы «Эмпиризм» записывается вид «направление»
- **THEN** значение сохранено и группа попадает в фильтр «Направление» карты

#### Scenario: Значение вне списка

- **WHEN** для события записывается вид «кулинарное»
- **THEN** утверждение отклонено с сообщением о допустимых значениях

#### Scenario: Роль из Wikidata

- **WHEN** у персоны в Wikidata род занятий «философ» и «математик»
- **THEN** у персоны роли «философ» и «учёный»

#### Scenario: Экономическое событие в существующей базе

- **GIVEN** реестр заполнен до этого изменения (без «экономического» вида события), в базе есть события с видом «политическое»
- **WHEN** сервис стартует и для события «Южноморский пузырь» записывается вид «экономическое»
- **THEN** значение сохранено, прежние утверждения на месте, версия реестра увеличена с записью о дозагрузке; в журнале `knowledge.statement.created` с `type=event_kind`

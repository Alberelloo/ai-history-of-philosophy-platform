# Proposal

Выделено из `pilot-launch` (группа 1 «Источники и онтология»), 2026-11-19. Добавлены оставшиеся шаги поиска источников из [журнала поиска](../../../sources/discovery-log.md).

## Why

Код библиотеки, онтологии и упоминаний готов и проверен на демонстрационных данных. Настоящих данных в системе нет:
- одобренные источники каталога не загружены на стенд или сервер;
- онтология не наполнялась настоящим извлечением;
- неоднозначные упоминания моделью не разрешались.

Без этих данных нельзя ни замерить качество (`pilot-evaluation`), ни открыть продукт читателям (`pilot-deploy`).

С 06.11, когда писался `pilot-launch`, обстоятельства изменились:
- каталог вырос до 317 записей: 304 одобрены, 10 отклонены, 3 черновика;
- у 18 одобренных источников вид лицензии `public-domain-ru` с `external_processing: false` (`sources/licenses.yaml`). Их тексты не уходят внешним моделям. Поэтому извлечение онтологии и разрешение упоминаний моделью по ним не идут.

## What Changes

- Загрузка 304 одобренных источников каталога командой `catalog sync` и проверка итога.
- Решение по трём черновикам каталога и установление переводчиков по каталогам РНБ и РГБ.
- Настоящее извлечение онтологии по одобренным источникам с разрешённой внешней обработкой и замер качества по типам связей. Для 18 источников без внешней обработки принимается отдельное решение.
- Офлайн-разрешение неоднозначных упоминаний моделью.

## Capabilities

### New Capabilities

Нет. Поведение уже описано в `openspec/specs/` (`source-catalog`, `source-registry`, `ontology-extraction`, `entity-mentions`). Это изменение про данные. Если работа потребует изменить поведение, например ручное наполнение онтологии для источников без внешней обработки, для этого заводится отдельное изменение со спецификациями.

### Modified Capabilities

Нет.

## Impact

- Данные: учёт источников, файловое хранилище, онтология, индекс упоминаний.
- `sources/catalog.yaml`: решения по черновикам и уточнённые переводчики.
- Расход на модели: извлечение и разрешение упоминаний идут в пределах бюджета наполнения (`config/llm.yaml`).
- Зависят от этого изменения: `pilot-evaluation` (все замеры) и `pilot-deploy` (первое развёртывание с данными).

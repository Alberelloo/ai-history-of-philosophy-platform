## MODIFIED Requirements

### Requirement: Виды лицензий как данные

Виды лицензий SHALL храниться как данные: название, ссылка, разрешения по умолчанию и регионы показа. Регионы показа — список кодов стран ISO 3166-1; пустой список или его отсутствие означает «везде». Оператор SHALL добавлять новый вид лицензии без изменения кода. Разрешения и регионы конкретного источника можно сузить относительно вида лицензии, но MUST NOT расширить. Действующие регионы источника — пересечение регионов вида лицензии и источника; пустое пересечение означает, что источник не открыт ни одному региону.

#### Scenario: Новая лицензия

- **WHEN** оператор добавляет вид лицензии «CC BY-NC 4.0» с разрешениями по умолчанию
- **THEN** её можно сразу указать у источника

#### Scenario: Сужение разрешений

- **WHEN** оператор запрещает у источника под CC BY отправку текста внешним сервисам
- **THEN** у этого источника внешняя обработка запрещена, а у остальных источников под CC BY нет

#### Scenario: Вид лицензии с регионом

- **WHEN** оператор добавляет вид лицензии «Общественное достояние по праву РФ» с регионами `[RU]`
- **THEN** у каждого источника с этим видом действующие регионы — `[RU]`

#### Scenario: Сужение регионов

- **GIVEN** у вида лицензии регионы `[RU, BY]`
- **WHEN** оператор сужает регионы источника до `[RU]`
- **THEN** у этого источника действующие регионы `[RU]`, у других источников этого вида `[RU, BY]`

#### Scenario: Расширение регионов

- **GIVEN** у вида лицензии регионы `[RU]`
- **WHEN** оператор указывает у источника регионы `[RU, DE]`
- **THEN** система отказывает: регионы источника нельзя расширять относительно вида лицензии

## MODIFIED Requirements

### Requirement: Список источников

Система SHALL показывать читателю список источников библиотеки. В список SHALL попадать только источники, которые опубликованы, разрешены к показу по лицензии, видны читателю по области видимости и открыты региону читателя. В первой версии аккаунтов нет, поэтому видны только источники с общей областью видимости.

#### Scenario: Открытие библиотеки

- **WHEN** читатель открывает библиотеку
- **THEN** система показывает все опубликованные источники с общей областью видимости, открытые его региону

#### Scenario: Источник ещё не опубликован

- **GIVEN** источник зарегистрирован, но его обработка не закончена или отложена
- **WHEN** читатель открывает библиотеку
- **THEN** этого источника нет в списке

#### Scenario: Лицензия не разрешает показ

- **GIVEN** у источника лицензия, которая не разрешает показывать текст
- **WHEN** читатель открывает библиотеку
- **THEN** этого источника нет в списке

#### Scenario: Источник с ограниченной областью видимости

- **GIVEN** область видимости источника — отдельный пользователь или группа
- **WHEN** читатель без доступа к этой области открывает библиотеку
- **THEN** этого источника нет в списке

#### Scenario: Источник закрыт для региона читателя

- **GIVEN** у источника действующие регионы `[RU]`
- **WHEN** библиотеку открывает читатель из другой страны или из неизвестного региона
- **THEN** этого источника нет в списке, и название его нигде не показывается

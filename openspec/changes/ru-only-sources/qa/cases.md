# Кейсы: ru-only-sources

Каталог изменения: `openspec/changes/ru-only-sources/`. Покрыты группы 1–6 `tasks.md` (учёт
регионов, библиотека, шлюз, поиск и индексация, сервис знаний, ассистент) и задача 8.2
(запасной регион стенда). Группы 7–8 (внешняя обработка, оценка, данные, развёртывание, архив)
добавят свои UC/TC/EC по мере работы.

Требования — `specs/source-registry/spec.md`, `specs/source-library/spec.md`,
`specs/chapter-reading/spec.md`, `specs/regional-access/spec.md`,
`specs/paragraph-search/spec.md`; решения — `design.md`.

| R7 | regional-access / «Внутренние интерфейсы не фильтруют по региону» | Внутренний интерфейс версий и `published()` не теряют закрытые источники; `GET /internal/access?region=XX` отдаёт закрытые для региона идентификаторы |

| R9 | regional-access / «Внешняя обработка закрытых источников» | Внутренний ответ версии несёт `external_processing` (поле нужно группе 7; здесь только отдаётся) |

| R11 | regional-access / «Неизвестный регион закрывает ограниченные источники» | Нет заголовка страны, значение не двухбуквенный код или запрос не от доверенного прокси — регион неизвестен; запасной регион (`PHILOGRAPH_REGION_FALLBACK`) подставляет регион только для разработки и сквозных тестов, по умолчанию пуст |
| R12 | regional-access / «Регион читателя определяет шлюз» (сценарий «Регион не сохраняется») | Страна читателя не сохраняется и не попадает в журналы с привязкой к читателю; оператору доступна только обезличенная доля запросов с неизвестным регионом |
| R13 | regional-access / «Шлюз доступен только через CDN» | Проверка конфигурации развёртывания (прямой доступ закрыт, заданы заголовок страны и доверенный прокси) — задача 8.6, в группе 3 не реализуется |
| R14 | regional-access / «Поиск учитывает регион запроса» | Поиск принимает регион запроса и возвращает абзацы только открытых региону источников (по словам и по смыслу); без региона — неизвестный регион; регионы хранятся в индексе и в полезной нагрузке векторного индекса, фильтр применяется до отбора результатов |
| R15 | regional-access / «Смена регионов у опубликованного источника» | Событие `source.access_changed` обновляет регионы в таблице `docs` и в полезной нагрузке векторного индекса без пересчёта эмбеддингов |
| R16 | regional-access / «Внутренние интерфейсы не фильтруют по региону» | Сверка индексов не гасит закрытые по региону источники как лишние; расхождение регионов индекса с библиотекой чинится |
| R17 | regional-access / «Неизвестный регион закрывает ограниченные источники» | Запасной регион (`PHILOGRAPH_REGION_FALLBACK`) подставляет регион стенду разработки и сквозным тестам (`RU`), по умолчанию пуст |
| R18 | regional-access / «Онтология не раскрывает текст закрытых источников» | Сервис знаний скрывает подтверждения, цитаты, ссылки на абзацы и атрибуции источника закрытых источников в карточках, графе, упоминаниях и контексте ассистента; утверждения остаются, статус не пересчитывается |
| R19 | regional-access / «Онтология не раскрывает текст закрытых источников» | Множество закрытых источников региона вычисляется сервисом знаний из `internal/access` по заголовку `X-Philograph-Region` (для `/internal/assistant/context` — по полю `region` тела) и передаётся в карточки, граф, упоминания и контекст ассистента; без заголовка регион неизвестен |
| R20 | regional-access / «Онтология не раскрывает текст закрытых источников» | Недоступная библиотека при `internal/access` — безопасный отказ: сервис знаний отвечает 503 `knowledge_unavailable` и не отдаёт непроверенные подтверждения |
| R21 | regional-access / «Ассистент не использует закрытые источники» | Ассистент передаёт регион читателя в поиск и в сервис знаний; абзацы, цитаты, ссылки и подтверждения закрытых источников не попадают ни в запрос к модели, ни в ответ |
| R22 | regional-access / «Ассистент не использует закрытые источники» | Закрытый источник в запросе (текущий учебник, абзацы выделения) — ассистент работает, как будто источника нет: выделение и `source_id` игнорируются |
| R23 | answer-grounding / «Проверка ссылок кодом» | Ссылка на непереданный или несуществующий абзац (в т.ч. из закрытого источника, отсечённого регионом) удаляется; фрагмент без других ссылок — неподтверждённый |

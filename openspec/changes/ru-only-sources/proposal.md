# Proposal

## Why

Вид лицензии `public-domain-ru` (`sources/licenses.yaml`) помечает источники, у которых срок охраны по ст. 1281 ГК РФ истёк, но в США текст может быть ещё защищён. Владелец решил показывать такие источники только читателям из РФ. Сейчас вид лишь метка: библиотека, поиск, ассистент и карточки отдают эти тексты всем, а в каталоге уже 17 одобренных записей с этим видом. Без ограничения по региону такие источники нельзя публично запускать.

## What Changes

- Новое понятие «регионы показа»: у вида лицензии и у источника (сужение, как у `narrowed`) может быть список кодов стран; пусто означает «везде». `public-domain-ru` получает `regions: [RU]`.
- Шлюз берёт страну читателя из заголовка CDN (имя заголовка задаёт настройка) и доверяет ему только запросу от доверенного прокси/CDN; сервисам передаёт код заголовком `X-Philograph-Region`. Заголовок региона от клиента отбрасывается. Регион не определён: ограниченные источники закрыты.
- Библиотека не отдаёт текст, оглавление и карточку источников, закрытых для региона читателя. В списке такой источник виден строкой «доступен в РФ» (название и автор), открыть его нельзя; он не становится источником по умолчанию или текущим. Ссылка на абзац отвечает `source_unavailable` без текста.
- Поиск принимает регион запроса и не возвращает абзацы закрытых источников ни по словам, ни по смыслу. Регионы хранятся рядом с абзацами в индексе; полная переиндексация не нужна, достаточно миграции и шага сверки. Полная переиндексация не нужна: миграция и шаг сверки.
- Ассистент передаёт регион в поиск и в сервис знаний, не получает из закрытых источников ни абзацы, ни цитаты, ни ссылки.
- Сервис знаний (карточки, граф, «где читать», подтверждающие абзацы, упоминания) скрывает подтверждения, цитаты, ссылки и атрибуцию закрытых источников. Сами утверждения онтологии остаются, в том числе подтверждённые только закрытым источником: это факты, а не текст источника.
- Смена регионов у опубликованного источника рассылается событием `source.access_changed`: индексы обновляются без пересчёта эмбеддингов и без повторной публикации.
- Внешняя обработка: у `public-domain-ru` `external_processing: false` (решение владельца), и сервисы действительно её соблюдают на всех шагах, включая ответ ассистента и разбор неоднозначных упоминаний.
- Оценка качества и служебные запросы задают регион явно.
- **BREAKING** для разработки и для читателей из РФ без распознанного региона (или через VPN): ограниченные источники им недоступны, подтверждения «я в РФ» нет (решение владельца). Для разработки: без заданного региона 17 источников каталога не видны в стенде. Для разработки и сквозных тестов вводится настройка запасного региона.

## Capabilities

### New Capabilities

- `regional-access`: определение региона читателя по заголовку CDN, требование «шлюз только через CDN», правило «регион неизвестен — закрыто», что именно скрывается в библиотеке, поиске, ассистенте и онтологии, поведение ссылок на абзацы и событий при смене регионов, внешняя обработка закрытых источников.

### Modified Capabilities

- `source-registry`: «Виды лицензий как данные» — регионы показа у вида лицензии и источника, сужение без расширения.
- `source-library`: «Список источников» — источник, закрытый для региона читателя, показывается в списке строкой «доступен в РФ» без возможности открыть.
- `chapter-reading`: «Устойчивость ссылок на абзацы» — ссылка на абзац источника, закрытого для региона, отвечает «недоступен» без текста и главы.
- `paragraph-search`: «Видимость и публикация» — поиск не возвращает абзацы источников, закрытых для региона запроса.

## Impact

- Код: `src/philograph/gateway/` (определение региона, заголовок), `library/registry.py`, `library/reading.py`, `library/app.py`, `library/schema.py` (миграция), `library/catalog/` (модель, `catalog.schema.json`, синхронизация видов лицензий), `search/` (схема, индексация, запрос, векторное хранилище), `assistant/`, `knowledge/` (карточки, граф, упоминания, контекст ассистента), `evaluation/`.
- Данные: `sources/licenses.yaml` (поле `regions`, `external_processing: false` у `public-domain-ru`). Записи каталога не меняются.
- Развёртывание: шлюз в продакшене доступен только через CDN (иначе заголовок страны можно подделать); настройки `PHILOGRAPH_REGION_HEADER`, `PHILOGRAPH_REGION_FALLBACK`. Новых зависимостей нет.
- Схемы БД: миграция библиотеки (столбцы `regions`), миграция поиска (столбцы `regions`, `external`). Только добавление столбцов, откат кода на прежнюю версию остаётся возможным.
- Индексы: однократное обновление полезной нагрузки в векторной базе и столбца в таблице поиска; эмбеддинги не пересчитываются.
- Вне объёма: аккаунты и выбор региона читателем; хранение распределения читателей по странам (регион используется только в момент запроса); юридическая оценка основания (решение владельца); добавление источников.

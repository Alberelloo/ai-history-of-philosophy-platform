- Решения разработчика:
  1. **Автослияние** только по правилу `same_person`: QID не различаются, даты не противоречат, есть доказательство (один QID / общее основное название / пара написаний от модели). Сомнительное уходит в очередь. Ложное слияние хуже дубля: оно смешивает утверждения двух людей.

  4. Кэш `graph_extensions` удалённой при слиянии удаляется и при отмене не восстанавливается: это кэш.

### Решения разработчика по спорному (вопросов владельцу не задавалось)

1. **Английские источники.** Основное название — русское, если модель дала его и оно прошло проверку. Иначе — название упоминания. Так требует А1 (доля русских по всей онтологии) и русский интерфейс.
2. **Причина `empty`** добавлена пятой: пустая строка из П2 под «номер» не подходит.
3. **Пределы `sentence` — по типам в данных.** 6/80 по умолчанию, 12/160 для произведений и событий. Тип `source` не проверяется.
4. **Порядок причин** `empty` → `number` → `sentence` → `not_a_name` → `stopword`. Сценарий владельца «blind mathematician» → `not_a_name` выполняется, хотя слово есть и в стоп-списке.
5. **Даты.** `primary.dates` — четыре границы `FuzzyDate` в астрономическом счёте (требование `ontology-entities` «Нечёткие даты»). `{from, to, precision}` владельца — это `dates.span` и `precision`. Платон «427–347 до н. э.» хранится как (−426, −346). У владельца −427/−347 — исторический счёт.
6. **Персона с одним годом** не датируется (`dating:single_year`): рождение и смерть по одному числу не угадываются.
7. **`knowledge.entity.rejected` несёт `label`** до 80 знаков: публичное название из учебника или ввод оператора, не текст вопроса.
8. **API ручного создания сущности нет.** Сценарий «ручного» отказа — через `accept_core`.

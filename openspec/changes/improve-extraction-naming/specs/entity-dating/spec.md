## ADDED Requirements

### Requirement: Извлечение дат

Модель SHALL извлекать датировку сущности, если она названа в тексте: годы жизни персоны, год произведения, дату события. В схеме вывода извлечения SHALL быть поле датировки сущности с тремя частями:
- текст даты, как в источнике;
- номер абзаца;
- дословная цитата.

В промпте SHALL быть явное указание «извлекай годы, если они названы».

**Проверка сервером.** Датировка записывается, только если выполнены все условия:
- абзац лежит в пределах фрагмента;
- цитата есть в этом абзаце;
- текст даты разбирается правилом нечётких дат системы;
- каждое число года из текста даты встречается в цитате.

Иначе датировка MUST NOT записываться, и пишется событие `knowledge.extraction.dropped` с причиной:
- `dating:paragraph`;
- `dating:quote`;
- `dating:unparsed`;
- `dating:not_in_quote`;
- `dating:single_year` — у персоны один год вместо интервала: рождение и смерть не угадываются.

**Запись.** Датировка персоны SHALL храниться утверждением «годы жизни» (`lifespan`), прочих сущностей — утверждением «датировка» (`dating`). При записи у утверждения:
- подтверждение — абзац и цитата;
- атрибуция — источник;
- происхождение — «извлечено».

Основное значение SHALL попадать в `primary.dates` сущности. Годы до нашей эры SHALL храниться в астрономическом счёте. Отказ датировки MUST NOT отменять сущность и прочие утверждения фрагмента.

**Инвариант:** для любого элемента с датировкой, если датировка записана, то каждый её год есть в цитате, цитата есть в абзаце, а `span(primary.dates)` совпадает с разбором текста даты. Если датировка отклонена, утверждений `lifespan`/`dating` от неё нет и есть ровно одно событие `knowledge.extraction.dropped` с причиной `dating:*`.

#### Scenario: Дата жизни в тексте

- **WHEN** в абзаце «…Кант (1724–1804) …» модель возвращает `{name: "Кант", type: "person", dating: {text: "1724–1804", paragraph: 1, quote: "Кант (1724–1804)"}}`
- **THEN** у персоны «Кант» `span(primary.dates) = (1724, 1804)`, `precision="year"`, исходная запись «1724–1804»; утверждение `lifespan` с подтверждением этого абзаца
- **AND** в журнале `knowledge.statement.created` с `type="lifespan"`

#### Scenario: Дата до нашей эры

- **WHEN** в абзаце «Платон (427–347 до н. э.)» модель возвращает датировку `"427–347 до н. э."`
- **THEN** `span(primary.dates) = (−426, −346)` в астрономическом счёте, `precision="year"`
- **AND** в журнале `knowledge.statement.created` с `type="lifespan"`

#### Scenario: Год произведения

- **WHEN** в абзаце «„Критика чистого разума“ (1781)» модель возвращает датировку произведения `"1781"`
- **THEN** у произведения утверждение `dating`, `span(primary.dates) = (1781, 1781)`
- **AND** в журнале `knowledge.statement.created` с `type="dating"`

#### Scenario: Года нет в цитате

- **WHEN** модель возвращает для «Кант» датировку `"1724–1804"` с цитатой «Кант родился в Кёнигсберге»
- **THEN** датировка не записана, сущность и прочие утверждения фрагмента записаны
- **AND** в журнале `knowledge.extraction.dropped` с `reason="dating:not_in_quote"`

#### Scenario: Один год у персоны

- **WHEN** модель возвращает для персоны датировку `"1724"`
- **THEN** датировка не записана
- **AND** в журнале `knowledge.extraction.dropped` с `reason="dating:single_year"`

#### Scenario: Неразборчивая дата

- **WHEN** модель возвращает датировку `"в эпоху Просвещения"` с верной цитатой
- **THEN** датировка не записана
- **AND** в журнале `knowledge.extraction.dropped` с `reason="dating:unparsed"`

#### Scenario: Инвариант датировки

- **WHEN** на произвольных датировках (генератор: годы −3000…2100, интервалы, «до н. э.», «ок.», века; цитаты с годами и без; абзацы вне фрагмента) выполняется извлечение
- **THEN** каждая записанная датировка: все годы текста есть в цитате, цитата есть в абзаце, `span(primary.dates)` равен `span(parse(text))`; на каждую отклонённую — одно событие `knowledge.extraction.dropped` с `reason`, начинающейся с `dating:`, и нет утверждения датировки

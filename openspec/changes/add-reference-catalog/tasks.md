## 4. Задачи тестировщика

Тесты пишутся по дельтам спецификаций, а не по коду. Каждый тест — с маркером `@pytest.mark.req("<возможность>", "<требование>")`, проверяет вывод и событие журнала (фикстура `events`).

- [ ] 4.1 `tests/knowledge/test_catalog.py` — сценарные (`scenario=`) на каждое требование `entity-catalog` уровня сервиса: «Список справочника», «Поиск по названию», «Фильтры справочника», «Счётчики справочника», «Постраничная выдача», «Прежний поиск по названию», «Справочник и закрытые источники», «Свежесть справочника» (часы `ManualClock`, без `sleep`)
- [ ] 4.2 Нормативные (`invariant=`): слитые и `source` не попадают ни в список, ни в счётчики; текст поиска не попадает в журнал ни при каком запросе; сумма `facets.types` = `total` без фильтра типа; порядок устойчив и страницы не пересекаются (свойство на случайных данных с `seed`); справочник не вызывает модель; при закрытом учебнике `items` пусты для любых прочих фильтров
- [ ] 4.3 `tests/knowledge/test_epochs_membership.py` — сценарии и инварианты «Принадлежность к эпохе»: явное важнее дат, отклонённое не действует, `[from, to)`, несколько эпох, вывод не пишет утверждений, идеи без явного — без эпохи
- [ ] 4.4 `tests/gateway` — «Бесплатное без ограничений платных»: справочник без токена страницы при исчерпанных квотах — 200, `gateway.limit.triggered` нет, квоты не уменьшились
- [ ] 4.5 `tests/web/test_reference.py` (Playwright, Chromium) — «Страница справочника», «Состояния страницы справочника», «Клавиатура и доступность справочника», «Разделы в разработке» (`/soon/reference`, метка «скоро» снята): вывод в DOM и события сервиса знаний по `request_id`; раскладка 1024×576 и 1920×1080 без наложений (проверка по прямоугольникам)

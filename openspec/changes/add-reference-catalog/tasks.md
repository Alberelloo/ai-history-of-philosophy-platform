## 4. Задачи тестировщика

Тестировщик этого стека — Opus: задача 4.0 — новая тестовая инфраструктура (working-principles, раздел 4; решение ведущего Р1).

Тесты пишутся по дельтам спецификаций, а не по коду. Каждый тест — с маркером `@pytest.mark.req("<возможность>", "<требование>")`, проверяет вывод и событие журнала (фикстура `events`).

- [ ] 4.0 **Инфраструктура `tests/web`:** фикстура, поднимающая настоящее приложение знаний в процессе (SQLite, данные задаёт тест через `Entities`/`Statements`), шлюз проксирует к нему `/api/knowledge`; события `knowledge.*` видны фикстуре `events` по `request_id`; ловушки: сеть наружу и вызовы модели падают тестом; помощник `page.clock`. `?fixture=dense`, `seed_demo` и продуктовые фикстуры источником ожиданий не служат; `page.route` — только для 503, задержки и гонки. Её переиспользуют `add-epochs`, `add-epoch-context`, `add-geo-timeline`
- [ ] 4.1 `tests/knowledge/test_catalog.py` — сценарные (`scenario=`) на каждое требование `entity-catalog` уровня сервиса: «Список справочника», «Поиск по названию», «Фильтры справочника», «Счётчики справочника», «Постраничная выдача», «Прежний поиск по названию», «Проверка параметров справочника» (один параметризованный тест по таблице границ и `reason`), «Справочник и закрытые источники», «Свежесть справочника» (часы `ManualClock`, без `sleep`; таблица `fresh`/`cached`/`stale`)
- [ ] 4.2 Нормативные (`invariant=`): слитые и `source` не попадают ни в список, ни в счётчики; текст поиска не попадает в журнал ни при каком запросе; сумма `facets.types` = `total` без фильтра типа; порядок устойчив и страницы не пересекаются (свойство на случайных данных с `seed`); справочник не вызывает модель; при закрытом учебнике `items` и `facets` пусты для любых прочих фильтров; события `knowledge.catalog.*`/`knowledge.snapshot.built` содержат только id, коды и числа (проверка всех строковых полей на отсутствие текста запроса и названий); уникальная фраза абзаца не входит в тело ответа
- [ ] 4.3 `tests/knowledge/test_epochs_membership.py` — сценарии и инварианты «Принадлежность к эпохе»: явное важнее дат, отклонённое не действует, `[from, to)`, несколько эпох, вывод не пишет утверждений, идеи без явного — без эпохи

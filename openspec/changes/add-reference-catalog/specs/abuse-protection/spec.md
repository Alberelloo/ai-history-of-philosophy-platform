# abuse-protection — дельта

## MODIFIED Requirements

### Requirement: Бесплатное без ограничений платных

Чтение, библиотека, сохранённые карточки, граф из сохранённых связей и справочник MUST NOT зависеть от лимитов платных операций. Справочник SHALL ограничиваться только общим лимитом частоты запросов; токен страницы для него MUST NOT требоваться, а его запросы MUST NOT уменьшать остаток платных операций посетителя.

#### Scenario: Лимит исчерпан

- **GIVEN** посетитель исчерпал лимит вопросов
- **WHEN** он открывает главу и карточку
- **THEN** всё открывается

#### Scenario: Справочник при исчерпанном лимите

- **GIVEN** посетитель исчерпал лимит вопросов и достройки
- **WHEN** он открывает `/reference` и ищет «кант» без cookie токена страницы
- **THEN** ответ справочника 200, события `gateway.limit.triggered` для этого запроса нет; после этого остаток вопросов посетителя не изменился

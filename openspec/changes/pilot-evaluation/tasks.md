# Tasks

Выделено из `pilot-launch`. В скобках указано, откуда пришла задача. Для каждой задачи указано, что нужно от владельца. Все задачи ждут загрузки источников (`pilot-data` 1.1), задачи 1.3–1.5 ещё и наполнения онтологии (`pilot-data` 2.1–2.2).

## 1. Замеры

- [ ] 1.1 Первый настоящий набор вопросов по пилотному разделу «Теория познания» (add-evaluation-harness 1.8; pilot-launch 2.1). У каждого вопроса задано поле `region` (ru-only-sources 8.1). В набор входят вопросы, ответ на которые лежит в источниках без внешней обработки: по ним ассистент должен давать ссылки с пометкой, не пересказывая. **От владельца:** проверка эталонных ответов человеком, знающим предмет, или одобрение набора.
- [ ] 1.2 Замер провайдеров эмбеддингов на наборе 1.1 и выбор провайдера (add-paragraph-search 3.1, add-evaluation-harness 1.8; pilot-launch 2.2). Источники `public-domain-ru` в смысловой индекс не попадают, поэтому замер идёт только по источникам с внешней обработкой, и это указывается в отчёте. По итогу ADR-0002 переходит в статус «принято», указывается провайдер, в `config/llm.yaml` — его настройки. **От владельца:** ключи провайдеров-кандидатов и бюджет на замер.
- [ ] 1.3 Разметка абзацев пилотного раздела и замер точности и полноты упоминаний (add-entity-mentions-and-cards 1.10; pilot-launch 2.3). Результат делится на источники с разрешением моделью и без него (`pilot-data` 2.2). **От владельца:** разметчик или одобрение разметки, сделанной агентом.
- [ ] 1.4 Сравнение метрик ассистента с онтологией и без неё по шагам на наборе 1.1 (add-ontology-aware-assistant 1.9; pilot-launch 2.4). **От владельца:** ключ модели и бюджет на прогон.

## 6. Тесты по спецификации (тестировщик)

Тесты пишутся по дельтам, не по коду. Каждый тест проверяет вывод (ответ API или DOM) и событие `knowledge.card.served` с `request_id`; маркер `@pytest.mark.req(возможность, требование, scenario=… | invariant=…)`. Тесты MODIFIED-требований, чьи ожидания изменились (список в proposal.md, «Impact»), переписываются по новой спецификации, а не удаляются.

# Proposal

## Why

Общие вопросы читателя (шире книги) сейчас отвечаются в панели книги по одной книге, а раздел «Ассистент» — заглушка `/soon/assistant`. Владелец утвердил (reader-panels.md v1.2, Р3, Р10): общие вопросы уходят в раздел «Ассистент» по ссылке из границы выбора, страница раздела показывает свой набор сессий по всей библиотеке, а заглушка снимается.

Это шестой этап документа (раздел 16). Этапы 4 и 6 выходят одним выпуском: этап 4 перенёс старый общий диалог в `libraryDialogs`, который виден только на странице раздела.

## What Changes

- Сервер N12: поле запроса `context: "book" | "library"` (по умолчанию `"library"`), `handoff_declined: true` с `handoff_reason`, событие `{"type": "handoff", "reason": "broader" | "outside_book"}` при `context: "book"`.
- Блок границы S7a в панели: текст по причине и два выбора — «Продолжить в рамках этого источника» и ссылка «Перейти в „Ассистент“ и продолжить по всем источникам».
- Страница `/assistant` (5.10): диалог раздела (`libraryDialogs`), сессии, стадии и пометки из этапа 4, `ScopeToggle`, прилепленная форма.
- Поручение перехода с вопросом и защита от повторной отправки (5.10): вопрос отправляется ровно один раз, только при переходе по ссылке внутри приложения.
- Снятие заглушки: пункт навигации ведёт на `/assistant` без метки «скоро», `/soon/assistant` → `/assistant` (`replaceState`), `SoonPage` для `assistant` удаляется, `activeItem` отмечает `assistant`.

## Capabilities

### New Capabilities

- `assistant-page` (страница раздела «Ассистент» и перенос общего вопроса).

### Modified Capabilities

- `assistant-dialog`: MODIFIED «Общий вопрос»; ADDED «Раздел „Ассистент“», «Граница книги», «Переход с вопросом из панели».
- `visual-design`: MODIFIED «Разделы в разработке» (ассистент больше не заглушка).

## Impact

- Клиент: `AssistantPage.tsx` (новая страница), `AssistantPanel.tsx` (блок S7a и поручение), `App.tsx` (маршрут `/assistant`, `activeItem`, удаление `SoonPage` для assistant), `Sidebar.tsx` (ссылка на `/assistant`).
- Сервер ассистента: `service.py`, `models.py` (N12: `context`, событие `handoff`, `handoff_declined`).
- Тесты: T36, T41–T43, T46; снимки страницы «Ассистент» 1024 и 1920, обе темы; прослеживаемость.

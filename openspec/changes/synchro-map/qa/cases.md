# QA

## Требования

| R | Требование | Проверка |
|---|---|---|
| R1 | Карта раздела | сервис: современники, идея по труду, без даты; UI: подписи у значков |
| R2 | Выбор на карте | UI: Кант — цвета, линии только между людьми, чужие труды убраны; событие; переключение на приглушённого; Esc |
| R3 | Фильтры и поиск карты | UI: направления + окно, «Показано N из M», только проверенные, поиск «крит» |
| R4 | Панель карты | UI: свернуть/развернуть, сохранение состояния |
| R5 | Линзы и окно времени | UI: свернуть события, последняя линза, 1920×1080 без прокрутки страницы |
| R6 | Запрос графа (изм.) | e2e: из карточки — карта с выбранным; сервис: неподходящий рецепт |
| R7 | Показ графа (изм.) | UI: порядок по времени, отклонённые не показаны |
| R8 | Подробности связи (изм.) | e2e: щелчок по линии Кант — Юм |
| R9 | Пометка достроенного (изм.) | UI: пунктир, подробности, экспорт SVG |
| R10 | Ограничение размера (изм.) | сервис: `truncated`; UI: «показана часть» |
| R11 | Пустой граф (изм.) | UI: пустая область; выбранный без связей |
| R12 | Виды групп, роли, виды событий | сервис: список, вне списка, P106 |
| R13 | Типы сущностей в реестре (изм.) | сервис: датировка эпохи |
| R14 | Сцена карты | UI: тёмная тема и контраст; 1024 без предметов |
| R15 | Раскладка без наложений (изм.) | UI: подписи карты на 1280/1920 |
| R16 | Шрифты (изм.) | UI: записка Bad Script с сайта |

## Пользовательские сценарии

| UC | Шаги | Ожидание |
|---|---|---|
| UC1 | Карточка «причинность» → «генезис» | Карта, выбрано понятие, автор выделен |
| UC2 | Выбрать Канта → «Достроить связи» | Новые линии пунктиром, в «Выбрано» статус достройки |
| UC3 | Фильтр «эмпиризм» + окно 1630–1800 → поиск «Локк» | Локк выбран, адрес содержит фильтры и выбор; обновление страницы сохраняет вид |
| UC4 | Свернуть панель, свернуть страту событий | Карта шире и выше, ничего не наложено |
| UC5 | Тёмная тема, 1024px | Стол без предметов, лист читается, нет горизонтальной прокрутки |

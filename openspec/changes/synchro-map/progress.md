## 2026-11-18 — сцена (6.1–6.3)

Снимки стенда 1920×1080 светлая/тёмная, 1280, 1024 проверены глазами (стенд не закоммичен).

- Сервис (задачи 2.1–2.4, 3.1–3.4, 7.1): вид значения `enum` с проверкой по списку; `dating` для эпох; `group_kind`, `person_role`, `event_kind`; `load_defaults` дописывает недостающие коды и концы в существующий реестр; роли из Wikidata P106; названия значений в `ontology.{ru,en}.json` (раздел `values`, тест сверяет с реестром). `knowledge/map.py` (`SectionMap`), `GET /v1/map`, лимит шлюза `map`, кэш по отпечатку базы; демо-данные карты в `seed_demo.py` (новые персоны не меняют карточки Канта и Юма).

# Proposal

## Why

Интерфейс собран из стандартных элементов браузера: ссылки навигации слиплись, шрифт один на всё, нет иерархии и тёмной темы, панели перекрывают текст. Дизайн-система утверждена ([docs/design/design-system.md](../../../docs/design/design-system.md), живая версия — артефакт «Дизайн-система PhiloGraph»). Это первый шаг переделки интерфейса: основа, на которой затем переделываются экраны чтения, графа, ассистента, библиотеки и настроек.

## What Changes

- Токены дизайн-системы (`docs/design/tokens.json`) становятся единственным источником цветов, отступов, радиусов, теней и длительностей клиента; `tokens.css` генерируется из них.
- Шрифты Literata и Onest подключаются локальными файлами.
- Стили компонентов дизайн-системы (`docs/design/system/components.css`, классы `pg-*`) применяются ко всем существующим экранам вместо стандартных элементов браузера.
- Верхняя панель на всех экранах: знак, название, навигация, язык, тема, настройки.
- Тема: светлая, тёмная, как в системе.
- Язык интерфейса: русский и английский, каталог строк.
- Визуальная проверка в сквозных тестах: проверки оформления по DOM и сравнение снимков экранов с эталонами.

## Capabilities

### New Capabilities

- `visual-design`: оформление клиента по дизайн-системе, темы, язык интерфейса, раскладка без наложений и визуальная проверка.

### Modified Capabilities

Нет: поведение экранов не меняется, меняется оформление. Глубокая переделка экранов — следующими изменениями.

## Impact

- Веб-клиент: стили, верхняя панель, каталог строк, хранилище настроек (тема, язык).
- Тесты: помощники визуальной проверки, эталонные снимки, локаль сквозных тестов.

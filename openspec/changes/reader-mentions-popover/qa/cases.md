# Кейсы: reader-mentions-popover

Источник задания: [docs/design/features/reader-panels.md](../../../../docs/design/features/reader-panels.md), этап 2 (разделы 4.1–4.7). Кейсы T6–T11, T15 — из раздела 14.2 документа.

## Требования

| REQ | Источник | Формулировка (SHALL) |
| --- | --- | --- |
| R1 | entity-mentions «Показ при чтении» | Упоминания SHALL выделяться пунктирным подчёркиванием цвета семьи; вид SHALL переключаться настройкой |
| R2 | entity-mentions «Показ при чтении» | Без онтологии глава SHALL показываться без упоминаний, а не с ошибкой |
| R3 | entity-cards «Карточка рядом с текстом» | Карточка SHALL открываться компактным окном только по щелчку/Enter/Space; наведение MUST NOT открывать |
| R4 | entity-cards «Карточка рядом с текстом» | Полная карточка SHALL открываться кнопкой «Открыть карточку» в правой панели |
| R5 | reader-settings «Набор настроек» | Настройка вида упоминаний SHALL входить в набор настроек, по умолчанию «подчёркивать» |

| ID | Сценарий | Актор | Предусловия | Шаги | Ожидаемый результат | REQ |

| UC-1 | Открыть карточку у термина | Читатель | Глава с упоминанием «Юм» | Щёлкнуть по «Юм» | Компактное окно у строки, не перекрывает строку упоминания | R3 |
| UC-2 | Наведение не открывает окно | Читатель | Глава с упоминанием | Навести и держать 2 с | Окна нет, запроса карточки нет | R3 |
| UC-3 | Открыть полную карточку | Читатель | Открыто окно у «Юм» | Нажать «Открыть карточку» | Полная карточка в правой панели, окно закрыто | R4 |

## Краевые случаи (EC)

| ID | Категория | Ситуация | Ожидаемое поведение | Приоритет |
| --- | --- | --- | --- | --- |
| EC-1 | Пустые данные | Упоминание без `entity_type` | Нейтральное подчёркивание `ink-2`, фон `sunken` | Высокий |
| EC-2 | Пустые данные | Карточка без описания и утверждений | После головы «Подробностей пока нет…», действия | Средний |
| EC-3 | Границы | Упоминание в последней видимой строке | Окно переворачивается вверх (низ окна выше верха строки) | Высокий |
| EC-4 | Границы | Окно у правого края (нет поля) | Не выходит за правый край окна, не создаёт прокрутки | Высокий |
| EC-5 | Ошибки | Карточка 404 `entity_not_found` | S3 «Карточки нет…», не S3a | Высокий |
| EC-6 | Ошибки | Карточка 5xx/сеть | S3a «Карточку не удалось загрузить…», «Повторить» | Высокий |
| EC-7 | Повтор/конкурентность | Щелчок по другому упоминанию во время загрузки | Запрос прежней карточки отменяется, окно переезжает | Высокий |
| EC-8 | Повтор | Повторное открытие той же карточки | Ответ из кэша, без запроса | Средний |
| EC-9 | Доступность | Только клавиатура: Tab к упоминанию, Enter, Tab из окна | Фокус виден, окно открывается, Tab из последнего элемента закрывает окно | Высокий |
| EC-10 | Доступность | Протяжка выделения, начатая на упоминании | Выделение текста, окно не открывается (сдвиг < 4px и пустое выделение) | Высокий |
| EC-11 | Миграция | Хранилище формата 3 без поля `mentions` | `normalize` приводит к `"underline"` | Высокий |

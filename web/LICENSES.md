# Лицензии клиента

Зависимости, которые попадают в собранный клиент (`npm run build`). Версии зафиксированы в `package.json` и `package-lock.json`. Новая зависимость клиента дописывается сюда в том же PR.

| Пакет | Версия | Лицензия | Зачем |
|---|---|---|---|
| react, react-dom | 18.3.1 | MIT | интерфейс |
| @fontsource-variable/literata | 5.3.0 | OFL-1.1 | шрифт текста, локально |
| @fontsource/onest | 5.3.1 | OFL-1.1 | шрифт интерфейса, локально |
| d3-geo (и зависимости d3-array, internmap) | 3.1.1 (3.2.5, 2.0.3) | ISC | ортографическая проекция глобуса (geo-timeline), только во фрагменте глобуса |
| topojson-client | 3.1.0 | ISC | TopoJSON суши → GeoJSON, только во фрагменте глобуса |
| world-atlas, файл `land-110m.json` | 2.0.2 | ISC; данные — Natural Earth 1:110m, общественное достояние | суша и береговая линия глобуса, собраны в клиент (без внешних запросов) |

`commander` (MIT) — зависимость командной строки `topojson-client`, в сборку не попадает. Типы `@types/*` (MIT) — только для проверки типов.

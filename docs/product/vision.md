# Продуктовое видение

Зафиксировано 19.10.2026 по итогам обсуждения. Следующий шаг: system design.

## Что делаем

Новый формат учебника по истории философии: веб-платформу, где человек читает тему по выбранному доверенному источнику, видит, как ту же тему трактуют другие авторы, и может разобраться, откуда взялось любое понятие или идея и с чем они связаны. Встроенный ассистент отвечает на вопросы по выделенному месту текста со ссылками на источники.

## Аудитория

Открытый сайт для всех, кто хочет разобраться в истории философии. Студенты, у которых история философии идёт учебным курсом, только один из сегментов. Для них важен сценарий «учиться по тому учебнику, по которому читает преподаватель».

Апробацию в рамках ВКР проводим на студентах: эту группу проще собрать и сравнить с традиционным форматом обучения.

## Проблема

В порядке важности:

1. **Учебник статичен и задаёт одну авторскую парадигму.** Как написал автор, так и будет рассказано учение. Трактовок много, а увидеть учение с разных сторон в рамках одного учебника нельзя. Текущие технологии позволяют охватить тему шире.
2. **Материал разрознен и неполон.** В разных учебниках одни и те же темы раскрыты с разной полнотой или опущены, поэтому полную картину из одного источника получить трудно.
3. **Связи и контекст неявны.** Учение подаётся отдельно от того, на что оно отвечало, кто на него повлиял, к чему оно привело, и от социальных, политических и экономических событий эпохи. Восстанавливать это приходится самому.

Одной фразой: существующий формат учебника не позволяет учиться по выбранным доверенным источникам, видеть тему глазами разных авторов и понимать, как идеи связаны между собой и со своей эпохой.

## Как решаем

Основной путь пользователя:

1. Выбирает раздел и главу. По умолчанию выбран один из учебников библиотеки, его можно сменить, например на тот, по которому читает преподаватель.
2. Читает главу как в интерактивном онлайн-учебнике: текст, ссылки, визуализации, где они нужны.
3. Рядом с абзацами видит пометки о трактовках других авторов: где они пишут иначе и что добавляют.
4. Кликает на понятие или философа и получает карточку с визуализацией (скорее всего графом):
   - для философа: биография и связи с другими мыслителями;
   - для понятия: этимология и перевод (например, с греческого), откуда пришла идея, кто её критиковал, к чему она привела, с какими событиями эпохи связана.
5. Выделяет слово или предложение и задаёт вопрос ассистенту по этому месту. Ассистент отвечает со ссылками на источники и по запросу рассказывает, как об этом пишут разные авторы.

### Работа с несколькими источниками

Рассмотрели пять вариантов: один источник, трактовки рядом, синтез общего текста LLM, основной текст с «полями», ответ ассистента по запросу. Выбрали **основной текст выбранного учебника с трактовками других авторов на полях** плюс **ответ ассистента о разных трактовках по запросу**.

Почему не синтез общего текста: он стирает различия между авторами и создаёт новую анонимную «парадигму LLM», то есть работает против первой проблемы, и его трудно проверить экспертам.

Ключевая техническая сложность: учебники устроены по-разному (по персоналиям, по проблемам, по эпохам), поэтому сопоставлять их нужно по понятиям и темам из общего словаря, а не по главам. Эта же разметка служит основой графа.

## Что нового

| Аналог | Чего не хватает |
|---|---|
| NotebookLM, ChatGPT | отвечают по документам, но без учебной структуры, графа и сравнения авторов |
| Энциклопедии (Стэнфордская, Новая философская) | глубина, но статичный текст одной редакции |
| Графы влияний («influenced by» из Википедии) | связи без текста, контекста эпохи и объяснений |
| Онлайн-курсы (Stepik, Арзамас) | интерактивная форма, но один автор |

Наше отличие: чтение доверенного учебника с трактовками других авторов на полях, граф генезиса каждого понятия вместе с событиями эпохи и ассистент по выделенному месту со ссылками на источники. По отдельности эти элементы существуют, вместе в учебнике по истории философии их нет.

## Функционал

**Первая версия** (к сдаче кода 26.12.2026):

- библиотека из нескольких открытых источников с выбором основного;
- чтение глав;
- трактовки других авторов на полях;
- карточка понятия или философа с графом связей и контекстом эпохи;
- ассистент по выделенному тексту с цитированием источников.

**Следующий уровень:**

- загрузка своих материалов;
- возможность поделиться учебником или подборкой материалов по ссылке, например преподавателю со своими студентами;
- синтез текста из нескольких источников с помощью LLM.

## Как проверяем эффект

Две группы изучают одну тему: одна по традиционному учебнику, другая на платформе. Затем обе проходят тест на то, насколько полно человек охватил контекст и генезис изученной идеи. Удовлетворённость и вовлечённость измеряем опросом.

## Открытые вопросы

- **Раздел для пилота.** Архитектуру к периоду не привязываем. Конкретный раздел для валидационного набора и ручной проверки графа выбираем при сборе данных, по доступности открытых источников.
- **Доступность источников.** Свободно лицензированных современных учебников на русском мало. Кандидаты: учебники в общественном достоянии, первоисточники в открытых переводах, Википедия, энциклопедии с открытой лицензией.
- **Насколько строго ассистент держится выбранного источника** и когда предлагает альтернативные трактовки. Решаем в system design.

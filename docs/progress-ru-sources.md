## Проблемы

- Адаптер `archive_org` падает с `AttributeError: 'NoneType' object has no attribute 'endswith'`, если у записи нет лицензии в метаданных (Бердяев «Философия свободы» 1911 — `1911-2523026-0120`, Ильин «Религиозный смысл философии» — `1914-1923-1924`); эти записи не добавлены.
- Для archive.org адаптер сопоставляет автора с Wikidata по имени и ошибается (Гегель получил год смерти 1876): у всех записей archive.org авторы и годы заданы вручную в `override.metadata`.
- Python (urllib) не проходит проверку сертификата archive.org в этой среде; метаданные брались через curl.

- «Политика или государство (Платон; Карпов)»: страница-оглавление, книги лежат на отдельных страницах вне подстраниц; в `files` попали только оглавление и /ДО.

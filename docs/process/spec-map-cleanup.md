# Задача: чистка карты — атрибуция источника и только живые философы

Статус: **в очереди** (после карточек/аудита).
Исполнитель — Claude: сам разбирается в коде, собирает спеку, идёт по пайплайну.

## 1. Контекст

После деплоя исторической политической карты (`add-historical-polities`) карта выглядит лучше, но есть два дефекта:

1. **Атрибуция источника перекрывает карту.** Блок лицензии/источника Cliopatria (CC BY 4.0) — четыре длинные строки — висит поверх карты и закрывает заметную её часть.
2. **На карте остаются умершие философы.** Например, при выбранном 1763 г. показывается Декарт в Стокгольме, хотя он умер в 1650-м — более ста лет назад. Карта должна оставаться «чистой»: показывать только тех, кто **жив в рамках выбранного временного интервала**.

## 2. Требования

### 2.1. Атрибуция источника вне карты

- Блок атрибуции (источник/лицензия Cliopatria) MUST NOT перекрывать интерактивную область карты/глобуса.
- Предпочтительно: вынести **под карту** отдельной строкой/ссылкой, либо сделать **свёрнутый индикатор** («Источник: Cliopatria, CC BY 4.0 ⓘ»), по наведению/нажатию раскрывающий полную информацию.
- Полная информация при раскрытии сохраняется (лицензия CC BY 4.0, авторы, ссылка) — требование лицензии.
- На 1024×576 свёрнутое состояние не должно занимать площадь карты.

### 2.2. Только живые на выбранный год

- При выбранном годе T на карте показываются только философы, **живые в интервале** (год рождения ≤ T и год смерти ≥ T; если известен только год рождения — T ≥ рождения; если дат нет — не показывать как «живого», либо показывать с честной пометкой, решение в design.md).
- Умершие до T — MUST NOT показываться.
- Проверка: T=1763 — Декарт (1596–1650) отсутствует; Кант (1724–1804) присутствует.
- Фильтр применяется к медальонам и связям (не тянуть связи от невидимых персон).

## 3. Приёмочные критерии

| # | Критерий |
|---|---|
| M1 | Атрибуция не перекрывает карту; при свёрнутом состоянии карта не занята |
| M2 | При T=1763 Декарт не отображается, Кант отображается |
| M3 | Для каждого года T показываются ровно персоны с `birth ≤ T ≤ death` (по правилу из design.md) |
| M4 | Связи не показываются от/к отфильтрованным персонам |
| M5 | XSS-инвариант; `lint-imports`, traceability, `ruff` — чисто |
| M6 | 1024×576 без наложений и горизонтальной прокрутки |

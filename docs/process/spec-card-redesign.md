# Задача: редизайн карточек сущностей (персона + остальные типы)

Статус: **в очереди** — после `polities` и аудита (или параллельно, если сервер позволит).
Исполнитель — Claude: сам разбирается в причинах, продумывает дизайн, собирает спеку, идёт по пайплайну.

## 1. Контекст

Сейчас карточки сущностей в продукте выглядят так:

- **Карточка персоны:** есть «линия жизни», подпись статусов («проверено / N источников / N сгенерировано»), места и годы жизни перечислены плоско, влияние — с явными упоминаниями («так считают…»), у работ/чтения — лишние блоки.
- **Карточки остальных типов** (понятие, учение, термин, труд, событие, явление, группа, место): **в основном пустые** — есть заголовок/карточка, но содержимого нет. Даже у понятий и учений не пишется, к кому/чему они относятся.
- **Исключение:** эпохи — у них есть даты, этого достаточно.

Из-за этого карточки выглядят несодержательно, хотя онтология наполняется.

## 2. Что делает Claude

1. **Сам разобраться, почему карточки пустые:** прочитать код карточек (`web/src`), API-ответы (`/api/knowledge/v1/...`), проверить, какие поля реально есть в онтологии (сущности/утверждения/атрибуции) и почему для большинства типов пусто.
2. **Продумать дизайн карточки под каждый тип** (см. требования ниже), согласовать с данными онтологии (что можно показать, чего нет).
3. **Составить полную спеку** (OpenSpec change): дельты, макеты/сценарии, инварианты.
4. **Пайплайн:** прораб (умная модель) + субагенты по ролям; на каждое требование — исполняемая проверка-инвариант; матрица «требование → тест» в `verification.md`.

## 3. Требования — карточка персоны

Карточку привести к виду, близкому к Wikipedia/Wikidata, но компактному:

1. **Убрать «линию жизни»** (горизонтальная линия рождения→смерть). Достаточно: имя + год рождения (и, если есть, годы жизни) в шапке.
2. **Убрать текстовые подписи статусов** («проверено», «N источников», «N сгенерировано» и т.п.), если они повторяются у каждого элемента. Вместо этого — **цветовая индикация**: зелёный — проверено, красный/оранжевый — сгенерировано/не уточнено, и т. п. Легенду — один раз, не у каждого поля.
3. **Краткая сводка:** основной город/страна, к которой принадлежал, + год рождения. Годы жизни — кратко.
4. **Где жил:** несколько городов через запятую, в **свёрнутом виде**, с возможностью развернуть полный список.
5. **Влияние:** кто на него повлиял и кто вдохновился им — **кратким списком**, не все, без явных «так считают такой-то, такой-то труд». Факты подаются как проверенные (цвет/статус — цветом, не текстом).
6. **Позиции и учения:** школа/направление + основные интересы (например, «теория познания, метафизика, этика») — кратко.
7. **Труды:** список произведений (кратко).
8. **Скрыть блоки «где читать» и «где упоминается»** — лишнее.
9. **Ширина:** сейчас карточки ощущаются узкими — сделать их **шире** (больше места сводке и спискам). На 1024×576 сетка не ломается: карта/соседние панели не перекрываются, горизонтальной прокрутки страницы нет (допустима внутренняя прокрутка карточки).

## 4. Требования — остальные карточки

Для каждого типа сущности продумать свои ключевые поля (аналог инфобокса Wikidata), опираясь на то, что реально есть в онтологии:

| Тип | Что показывать в карточке (предложение) |
|---|---|
| Понятие | где встречается/употребляется, кем введено, что обозначает, разные трактовки (кратко) |
| Учение | к кому/чему относится, основные положения, последователи/критики (кратко) |
| Термин | определение, язык/происхождение, где используется |
| Труд | когда написан, кем, какие сферы/вопросы затрагивает |
| Событие | когда, где, что произошло, значение (кратко) |
| Явление | определение, где проявляется, значение |
| Группа | что за группа, состав/направление, время |
| Место | что за место, регион/страна, связанные сущности |
| Эпоха | **как есть** — даты; больше ничего не нужно |

Пустые карточки MUST NOT оставаться: если для типа нет данных, карточка показывает хотя бы «что известно» из связей (кто/что относится, куда входит) или честно пустое состояние с подсказкой, но не «белый экран».

| # | Критерий |
|---|---|
| C1 | Карточка персоны: нет линии жизни, нет повторяющихся текстовых статусов — только цвет |
| C2 | Карточка персоны: краткая сводка (страна/город + год), свёрнутые места, влияние списком, интересы, труды |
| C3 | Карточки остальных типов не пустые: у каждого типа есть свои поля и данные (или честное пустое состояние) |
| C4 | Понятия/учения показывают, к кому/чему относятся |
| C5 | Труды показывают автора, дату (если есть), сферы/вопросы |
| C6 | Цветовая индикация статуса едина, легенда один раз |
| C7 | XSS-инвариант: тексты — текст, не HTML |

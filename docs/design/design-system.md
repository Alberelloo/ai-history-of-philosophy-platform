# Дизайн-система

Решения по внешнему виду PhiloGraph: характер, цвета, шрифты, раскладка, движение, компоненты и порядок переделки экранов. Живая версия с токенами в двух темах и превью компонентов — артефакт [«Дизайн-система PhiloGraph»](https://claude.ai/artifact/6twqmfY2rxxBV3pgncmob3); значения токенов — [tokens.json](tokens.json).

## Исходные решения

Зафиксировано с владельцем продукта 2026-11-05.

| Вопрос | Решение |
| --- | --- |
| Характер | 80% современный инструмент (светлый, просторный, шрифт без засечек), 20% книга (текст источников и имена шрифтом с засечками) |
| Образец | magisteria.ru: оформление людей, списки и разделы, общая палитра; но холоднее |
| Устройства | только десктоп, адаптивно от 1024px до широких мониторов |
| Темы | светлая и тёмная, по умолчанию как в системе |
| Шрифты | Literata для чтения, Onest для интерфейса |
| Сноски | на полях рядом с текстом, на узком экране во всплывающем окне |
| Упоминания | тонкое пунктирное подчёркивание, ярче при наведении, выключается в настройках |
| Колонки | оглавление сворачивается, боковая панель сдвигает текст, а не перекрывает |
| Карточка | окно у упоминания, «Развернуть» открывает полную карточку в боковой панели |
| Граф | ось времени слева направо, узлы-карточки, плавное перемещение и масштаб, мини-карта |
| Сгенерированное | единый значок (ромб), тёплый фон, подсказка |
| Движение | сдержанное, 120–240 мс, отключается при «уменьшить движение» |
| Цвета | пастельные, с холодным уклоном |
| Тон текстов | спокойный, на «вы», без восклицаний |
| Языки | русский и английский сразу |
| Макеты | интерактивные страницы claude.ai |
| Вёрстка | свои CSS-переменные и компоненты, без тяжёлых библиотек |
| Порядок | по одному элементу: проработка, одобрение, только потом следующий |
| Портреты | до 7 разных изображений на персону, одно главное, остальные листаются; видно, что их несколько; без изображения — заглушка |

## Что исправляем

Аудит текущего интерфейса (снимки при ширине 1440 и 1100):

- ссылки навигации слиплись в одну строку («БиблиотекаАссистентНастройки»);
- панель ассистента и окно карточки перекрывают текст главы;
- граф занимает угол экрана, остальное пусто; узлы — одинаковые кружки;
- кнопки, флажки и списки — стандартные элементы браузера;
- нет иерархии шрифтов, один шрифт на всё;
- узкая колонка текста посреди пустого экрана.

## Характер

Холодная бумага, пастельные цвета для типов знания и глубокий синий для действий. Узнаваемых деталей две: портреты-медальоны в едином дуотоне, которые сводят гравюры и живопись разных эпох в одну серию, и мышление осью времени — линия жизни в карточке, граф по векам, знак логотипа (два узла на оси времени и дуга влияния). Всё остальное спокойно: одна выразительная вещь на экран.

## Цвет

Палитра задана в OKLCH и переведена в hex скриптом с проверкой контраста WCAG; все пары текста и фона проходят AA в обеих темах (основной текст — не ниже 7:1).

| Роль | Светлая | Тёмная |
| --- | --- | --- |
| `paper` — фон | #eff1ec | #13171e |
| `surface` — окна, панели | #fafbf8 | #1c2128 |
| `ink` — текст | #1a222f | #e7e6df |
| `accent` — действия | #385b8f | #a4beef |
| `generated` — сгенерированное | тёплый песочный | тёплый песочный |

Пять семей сущностей — люди, понятия, учения, произведения, история — имеют пару «тон + подложка» и разную форму значка, чтобы их различали и без цвета. Полный список токенов с назначением — в [tokens.json](tokens.json) и в артефакте.

## Шрифты

- Literata: текст источника 19/31 в колонке 66–72 знака, заголовки глав, сноски, имена сущностей и названия произведений. Кегль текста читатель меняет в настройках.
- Onest: весь интерфейс, ответы ассистента. Шкала 12–34px.
- В продукте шрифты подключаются локально из @fontsource, без запросов к Google Fonts.

## Раскладка

Только десктоп, три ширины: 1024–1279, 1280–1599, от 1600. Колонка текста никогда не уже 60 знаков; поле справа занято сносками и номерами страниц; боковая панель сдвигает колонки; окно карточки встаёт на поле и не закрывает строку. Схемы — раздел «Экраны и раскладка» в артефакте.

## Компоненты первой волны

Button, SegmentedControl, Switch, TextField, EntityChip, StatusMark, Citation, Mention, Sidenote, Portrait, PortraitGallery, Lifeline, ListRow, Popover, SidePanel, Tooltip, Notice. У каждого в артефакте — правила и живое превью в обеих темах.

## Портреты

- Источник: Wikidata (P18) и категория персоны на Wikimedia Commons, только свободные лицензии; автор, год и ссылка на файл сохраняются и показываются под портретом.
- До семи изображений; дубли отсекаются по перцептивному хешу. Дублями считаются и разные фотографии одной картины, и гравюра с той же композиции: при подборе образцов для дизайн-системы из 11 найденных портретов Канта, Юма и Локка три оказались такими дублями.
- Медальоны — в дуотоне, галерея в карточке — в оригинальных цветах.
- Нет изображения — монограмма шрифтом чтения на подложке семьи со штриховкой.

## Языки

Каталог строк `ru` и `en` с одинаковыми ключами; сервер отдаёт коды, клиент показывает текст на языке интерфейса. Термины и форматы дат — раздел «Тексты и языки» в артефакте.

## Порядок работы

Каждый элемент: макет в артефакте → одобрение → изменение OpenSpec → код → сквозные тесты в браузере, включая сравнение снимков экрана → PR.

1. Дизайн-система: токены, шрифты, базовые компоненты, переключение темы и языка.
2. Экран чтения с упоминаниями, сносками на полях и карточкой (окно и полная карточка с галереей).
3. Граф по оси времени.
4. Ассистент.
5. Библиотека.
6. Настройки и уведомление при первом входе.

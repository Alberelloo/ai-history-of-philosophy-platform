# Тексты и языки

Интерфейс сразу на двух языках: русском и английском. Язык выбирается переключателем RU / EN в верхней панели и в настройках; по умолчанию — язык браузера (русский, если браузер русский, иначе английский). Тексты источников не переводятся; ассистент отвечает на языке вопроса.

## Тон

- Спокойно и по делу, на «вы» (EN — нейтральное «you»). Без восклицаний, без извинений, без шуток.
- Кнопка говорит, что произойдёт: «Открыть карточку», «Спросить», «Сбросить все данные». Сообщение после действия использует то же слово: «Данные удалены».
- Ошибка называет причину и выход: «Пароль не подошёл. Проверьте раскладку и попробуйте ещё раз.»
- Пустое состояние предлагает следующий шаг: «Связей пока нет. Включите достройку моделью или выберите другой рецепт.»
- Регистр как в предложении; заглавные буквы для подписей не используются.

| Понятие | RU | EN |

| Сгенерировано моделью | Сгенерировано | Generated |

| Источники расходятся | Спорно | Disputed |

## Числа и даты

- Годы жизни через короткое тире без пробелов: 1724–1804. До нашей эры: «ок. 428–348 до н. э.» / «c. 428–348 BCE». Века римскими цифрами: «XVIII в.» / «18th c.».
- Номер страницы печатного издания: «с. 45» / «p. 45».
- Счётчики со словом в правильной форме: «1 упоминание», «2 упоминания», «5 упоминаний» (EN: 1 mention, 2 mentions).

## Правила для разработки

- Все строки интерфейса — в одном каталоге (`ru` и `en` с одинаковыми ключами). Строка, которой нет в каталоге, — ошибка сборки.
- Сервер отвечает кодами (`kind`, `reason`), а клиент показывает текст на языке интерфейса. Текст сервера — только запасной вариант.
- Имена сущностей показываются на языке интерфейса, если есть такое название; иначе — на языке оригинала.

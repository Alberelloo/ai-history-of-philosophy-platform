# graph-f02-lenses — hero-концепт раскладки «линзы»

Статичный **концепт** нового решения графа Ф0.2 из
[предложения о линзах](../../../features/graph-lenses-design-proposal.md). Не продуктовый макет и не
замена `graph-f02/` (тот проходит 35/35) — это один кадр для сверки внешнего вида **до** проводки
интерактива (п.8 предложения, решение владельца «сначала hero-кадр»).

## Что показывает

Синхронологическая карта на столе: горизонталь — время, вертикаль — 4 **страты-линзы**
(сверху вниз): **События мира → Контекст·эпохи → Люди → Труды и мысли**. Общая шкала времени внизу.

- **Люди** — портреты-медальоны (сохранены из v1) как якоря **линий жизни** (рождение→смерть),
  имя и годы. Влияния — монотонные кривые слева-направо, привязка к **истинному контуру** эллипса
  (чинит прежний баг «концы не на узлах»).
- **Труды** — фолиант-/ромб-марки на году написания, вертикальный коннектор авторства к линии жизни.
- **Контекст** — эпохи как пролёты-территории. **События мира** — кольца на году.
- Материал стола/листа, нейтлиния, направленный свет — унаследованы от v1.
- «Клетка» убрана: разлиновка теперь осмысленная (вертикали = время, горизонтали = границы страт).

Эпохи и мировые события — **демо** (genesis их не содержит), добавлены, чтобы показать все 4 страты.

## Сцена «стол философа» — `desk.html` (текущий макет)

Рабочий лист на столе философа: орех, кожаный бювар, бумага с рельефом, книги, чернильница, заметки
от руки; на листе — синхронологическая карта с линзами. Интерактив: тоггл «глаз» у страты
сворачивает её (остальные забирают высоту); клик/Enter по философу — его влияния, труды, эпоха;
клик по полю или Esc — снять выбор. Светлая тема — день, тёмная — вечер при лампе.

Всё на листе строится из данных и следует за выбором: ленты, нити, труды, эпоха, сноска «Выбрано»,
заголовок, карточки на столе (цитата с источником, труды «к чтению»). На самом таймлайне
рукописных пометок нет — только данные. Нет данных —
нет пометки. Граф рисуется в реальных пикселях листа и пересчитывается при изменении окна.

Данные — `desk-data.js`: `desk.html` (демо, 5 философов) и `desk.html?data=dense` (синтетический набор
реального объёма: 41 философ, 64 труда, 50 влияний). При >12 философах — плотный режим: тонкие ленты
с именем внутри, медальон только у выбранного, связи — по выбору.

Файлы: `desk.html` · `desk.css` · `desk-data.js` · `desk-chart.js` (граф от данных и состояния) · `desk.js` (предметы) ·
`desk-light.png`/`desk-dark.png` · плотный набор — `cycle/v4-dense-*.png`. Направление — [graph-desk-scene-direction.md](../../../features/graph-desk-scene-direction.md),
журнал доводки — [design-cycle-log.md](../../../features/graph-page-qa/design-cycle-log.md).
Проверки (Playwright + Chromium): `cycle/check.js` (рендер, геометрия), `cycle/ixn.js` (интеракции),
`cycle/audit.js` (контраст), `cycle/dense.js` (плотный набор); запуск — `node cycle/<скрипт>.js` из папки с `playwright-core`.

## v2 — пробный кадр «выбран Кант» (отзыв 2026-11-17)

`trial.html` · `trial.js` (+ `trial-light.png`/`trial-dark.png`) — второй пробный кадр по отзыву:
- **линзы сворачиваемые** (глаз-тоггл): «События мира» свёрнута, остальные расширились;
- **связи — «волшебные нити»** без стрелок: градиент источник→киноварь, светящийся сужающийся пучок;
- **без вертикальных линий трудов**; по выбору персоны — её **влияния** (киноварь-пучки) и **труды**
  (бирюзовое гало + нить) подсвечены по-разному, остальное приглушено. Спиноза — демо-персона без связей.

Обоснование и референсы — в [предложении, раздел 10](../../../features/graph-lenses-design-proposal.md).

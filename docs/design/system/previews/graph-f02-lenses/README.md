# graph-f02-lenses — hero-концепт раскладки «линзы»

Статичный **концепт** нового решения графа Ф0.2 из
[предложения о линзах](../../../features/graph-lenses-design-proposal.md). Не продуктовый макет и не
замена `graph-f02/` (тот проходит 35/35) — это один кадр для сверки внешнего вида **до** проводки
интерактива (п.8 предложения, решение владельца «сначала hero-кадр»).

## Что показывает

Синхронологическая карта на столе: горизонталь — время, вертикаль — 4 **страты-линзы**
(сверху вниз): **События мира → Контекст·эпохи → Люди → Труды и мысли**. Общая шкала времени внизу.

- **Люди** — портреты-медальоны (сохранены из v1) как якоря **линий жизни** (рождение→смерть),
  имя и годы. Влияния — монотонные кривые слева-направо, привязка к **истинному контуру** эллипса
  (чинит прежний баг «концы не на узлах»).
- **Труды** — фолиант-/ромб-марки на году написания, вертикальный коннектор авторства к линии жизни.
- **Контекст** — эпохи как пролёты-территории. **События мира** — кольца на году.
- Материал стола/листа, нейтлиния, направленный свет — унаследованы от v1.
- «Клетка» убрана: разлиновка теперь осмысленная (вертикали = время, горизонтали = границы страт).

Эпохи и мировые события — **демо** (genesis их не содержит), добавлены, чтобы показать все 4 страты.

## Файлы

`index.html` · `style.css` (материал v1 + страты) · `concept.js` (статичная отрисовка SVG) ·
`preview-light.png` / `preview-dark.png` (снимки). Шрифты и портреты берутся из `../graph-f02/assets/`.

## Открыть

Любой статический сервер из `docs/design/system/previews/`, напр. `python3 -m http.server`,
затем `graph-f02-lenses/`. Снимки сняты headless-chromium (1320×760).

# SegmentedControl

Выбор одного из двух–четырёх равноправных вариантов, видимых сразу: язык интерфейса, тема, вид подчёркивания упоминаний.

Подложка `sunken` с рамкой `line`, активный сегмент поднят: `surface` и `shadow-raise`. Переход занимает `dur-base`. Каждый сегмент — `button` с `aria-pressed`; группа подписана через `aria-label`. Для пяти и более вариантов используйте выпадающий список.

| Где | RU | EN |
| --- | --- | --- |
| Язык | RU / EN | RU / EN |
| Тема | Светлая / Тёмная / Как в системе | Light / Dark / System |
| Упоминания | Подчёркивать / При наведении | Underline / On hover |

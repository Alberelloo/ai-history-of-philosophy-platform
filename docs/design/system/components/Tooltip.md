# Tooltip

Короткая подсказка к значку или сокращению: что делает кнопка, что значит пометка.

Фон `ink`, текст `paper`, `ui-caption`, радиус `radius-xs`. Появляется через 400ms наведения или сразу при фокусе с клавиатуры, исчезает за `dur-quick`. Не больше одной строки смысла, без точки в конце; длиннее — уже `Popover`. Кнопкам-значкам подсказка обязательна.

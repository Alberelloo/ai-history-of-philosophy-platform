# StatusMark

Что известно о строке знания: проверена ли она человеком, опирается ли на источник, написана ли моделью, спорна или противоречит источникам.

| Статус | Значок | Цвет | Когда |
| --- | --- | --- | --- |
| Проверено | галочка | `ok` | утверждение подтвердил оператор |
| По источникам | книга | `ink-2` | есть цитата из абзаца |
| Сгенерировано | ромб | `generated` на `generated-tint`, пунктир `generated-line` | модель, без опоры |
| Спорно | весы | `ink-2` | источники расходятся |
| Противоречит | треугольник | `danger` | ответ расходится с проверенным |

Сгенерированное всегда выглядит одинаково: ромб, тёплый фон и пунктирная рамка (`pg-generated` для фрагмента текста). Тёплый тон намеренно выбивается из холодной палитры. В плотных строках оставляйте только значок (`pg-status--icon-only`) с подсказкой.

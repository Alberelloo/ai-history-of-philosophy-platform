# Popover

Окно карточки рядом с упоминанием: кто это, годы, чем связан с текстом, где читать дальше. Не уводит из главы и не сдвигает текст.

Ширина `popover`, фон `surface`, рамка `line`, радиус `radius-md`, тень `shadow-pop`. Окно ставится на поле справа от строки, если там есть место, иначе под строкой; оно никогда не закрывает строку с упоминанием. Открывается только щелчком или Enter/Space на упоминании: наведение указателя окно не открывает и запрос карточки не отправляет. Появление: прозрачность, сдвиг на 4px и масштаб от 0.98 за `dur-base` по `ease-out`; закрытие за `dur-quick`. Esc, клик мимо и повторное нажатие на упоминание закрывают окно; фокус возвращается к упоминанию.

Состав: медальон (`Portrait`, одно главное изображение; остальные — только в полной карточке), имя `name-md`, метка семьи, годы, одна-две фразы описания (сгенерированное помечено `pg-generated`), до двух утверждений с пометкой статуса значком, без переключателей источников, действия «Открыть карточку» (боковая панель) и первый рецепт графа по типу сущности.

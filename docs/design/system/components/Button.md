# Button

Кнопка запускает действие; подпись говорит, что произойдёт («Открыть карточку», «Спросить»), а не «ОК».

- `pg-btn--primary`: одно главное действие в области (отправить вопрос, применить). Заливка `accent`, текст `on-accent`.
- `pg-btn--secondary`: обычное действие рядом с главным. Фон `surface`, рамка `line-strong`.
- `pg-btn--ghost`: действия в панелях и строках, где рамки дают шум. Текст `ink-2`, при наведении фон `sunken`.
- `pg-btn--icon`: только значок; у кнопки обязателен `aria-label` и подсказка `Tooltip`.
- `pg-btn--sm`: в плотных строках и окне карточки; высота `control-sm`.

Высота `control` (36px), радиус `radius-sm`, фокус `focus-ring`. Нажатие сдвигает кнопку на 1px за 80ms. Недоступная кнопка полупрозрачна; если причина неочевидна, рядом объясняется почему.

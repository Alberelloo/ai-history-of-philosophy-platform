# EntityChip

Метка типа сущности: где сущность упомянута в списке, карточке, графе.

Пять семей, у каждой свой цвет **и** форма значка, чтобы их различали и без цвета:

| Семья | Типы | Цвет | Значок |
| --- | --- | --- | --- |
| `people` | персона, группа | `people` на `people-tint` | круг |
| `ideas` | понятие, термин, концепция | `ideas` на `ideas-tint` | квадрат |
| `teachings` | учение, проблема, позиция, аргумент | `teachings` на `teachings-tint` | треугольник |
| `texts` | произведение, источник | `texts` на `texts-tint` | вертикальный прямоугольник |
| `history` | событие, эпоха, место, идейное событие | `history` на `history-tint` | кольцо |

Метка-ссылка (`a.pg-chip`) при наведении получает тонкую рамку своего цвета. Радиус `radius-xs`: метка почти прямая, чтобы не путать её с кнопкой.

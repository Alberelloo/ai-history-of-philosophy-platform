# FilterMenu

Выпадающий фильтр с флажками: несколько значений одного признака (вид источника, язык). Заменяет ряд меток, который менял ширину строки поиска. Эталоны — `docs/design/reference/FilterMenu-light.png` и `FilterMenu-dark.png`.

## Кнопка

- `pg-btn pg-btn--secondary`, справа шеврон `chevronDown`. Подпись — название признака; если что-то выбрано, через точку число выбранных: «Вид · 2». Число — `tabular-nums`.
- `aria-expanded`, `aria-controls` на окно. Открытый фильтр — шеврон повёрнут, рамка `accent`.

## Окно

- Под кнопкой, по левому краю; ширина по содержимому, не уже кнопки и не уже 220px. Фон `surface`, рамка `line`, радиус `radius-md`, тень `shadow-pop`, `z-popover`. Появление — как у `Popover`: прозрачность и сдвиг на 4px за `dur-base`; при «уменьшить движение» — только прозрачность.
- Сверху две кнопки `pg-btn--ghost pg-btn--sm`: «Выбрать все» и «Снять все». Неактивна та, что ничего не изменит.
- Ниже, через линию `line`, список флажков: настоящий `input type="checkbox"` внутри подписи, строка высотой `control-sm`, наведение `sunken`.
- Пустой выбор означает «все значения», как и прежде; «Выбрать все» — явный выбор всех.

## Поведение

- Открывается щелчком или Enter/пробелом на кнопке; фокус переходит на первую кнопку окна.
- Закрывается по Esc (фокус возвращается на кнопку), по щелчку вне окна и повторным нажатием кнопки. Выбор применяется сразу, без кнопки «Готово».
- Открыт один фильтр за раз.

## Строка фильтров

Поиск постоянной ширины (360px), за ним фильтры, за ними «Сбросить поиск и фильтры». Кнопка сброса всегда на месте: неактивна, если сбрасывать нечего. Строка не меняет ширину поиска ни при выборе, ни при вводе запроса.

| Где | RU | EN |
| --- | --- | --- |
| Кнопки окна | Выбрать все / Снять все | Select all / Clear all |
| Кнопка | Вид · 2 | Kind · 2 |

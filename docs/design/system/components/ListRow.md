# ListRow

Нумерованный список, где номер цветной, первая фраза строки полужирная, а под ней мелкие подробности: оглавление учебника, «где читать», результаты поиска, источники ответа.

Номер `accent` с табличными цифрами, ведущая фраза `ink` 600, продолжение `ink-2`, подробности `ui-caption` в `ink-3`. Между группами верхнего уровня волосяная линия `line`.

Вложенность видна сразу: строка следующего уровня (`pg-list__item--sub`, `--level: 1, 2…`) сдвигается на ширину номера, а линии `line-strong` соединяют номер родителя с номерами его строк, как ветви дерева. От родителя (`data-children`) вниз идёт линия, к каждой дочерней строке — изгиб со скруглением; у последней дочерней строки (`data-tree="end"`) линия заканчивается изгибом, у остальных (`data-tree="mid"`) продолжается вниз. Номер вложенной строки пишется полностью: «1.2.1».

Строка-ссылка при наведении получает фон `sunken`. Справа можно поставить одно действие или статус (`pg-list__aside`).

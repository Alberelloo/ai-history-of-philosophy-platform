# Switch

Включает или выключает настройку, которая действует сразу, без кнопки «Сохранить».

Выключено: дорожка `sunken` с рамкой `line-strong`, точка `ink-3`. Включено: дорожка `accent`, точка `on-accent` крупнее и сдвинута. Состояние читается по форме, а не только по цвету. Подпись — что включается («Генерация без опоры на источники»), под ней при необходимости пояснение `pg-switch__hint` в `ink-3`. Вся строка кликабельна (`label`).

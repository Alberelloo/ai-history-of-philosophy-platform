# SidePanel

Боковая панель справа: полная карточка сущности, ассистент, подробности связи графа. Панель **сдвигает** колонку текста, а не ложится поверх неё.

Ширина `panel`, фон `surface`, рамка слева `line`, тень `shadow-panel`. Открытие: панель появляется за `dur-slow` по `ease-standard`, а колонки раскладки перестраиваются одним шагом без анимации ширины (текст не переносится покадрово). Содержимое панели имеет постоянную ширину. Заголовок панели: название, действия (развернуть, закрыть). Тело прокручивается само по себе.

На ширине окна 1024–1279px панель живёт в полоске 48px (`panel-strip`) у правого края и разворачивается по щелчку поверх текста, не меняя раскладку; сворачивается при возврате к тексту (щелчок или фокус в тексте, Esc, кнопка «Свернуть»). На ≥1280px панель сдвигает колонки.

На K1 поле сносок остаётся. На K2/K3/K4 сноски — во всплывающих окнах, чтобы колонка текста не стала уже 62ch. При открытой панели оглавление сворачивается в полосу (K3) или скрывается (K4), если свободной ширины не хватает.

Одновременно открыта одна панель. Карточка, открытая при работающем ассистенте, встаёт в ту же панель с кнопкой «Назад к ассистенту».

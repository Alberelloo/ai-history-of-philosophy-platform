# SidePanel

Боковая панель справа: полная карточка сущности, ассистент, подробности связи графа. Панель **сдвигает** колонку текста, а не ложится поверх неё.

Ширина `panel`, фон `surface`, рамка слева `line`, тень `shadow-panel`. Открытие: колонки раскладки перестраиваются за `dur-slow` по `ease-standard`, текст переносится на новую ширину. Содержимое панели имеет постоянную ширину и не сжимается во время анимации. Заголовок панели: название, действия (развернуть, закрыть). Тело прокручивается само по себе.

На `bp-wide` поле сносок остаётся. На `bp-regular` при открытой панели сноски переходят во всплывающие окна, чтобы колонка текста не стала уже 60 знаков. На `bp-compact` при открытой панели сворачивается оглавление.

Одновременно открыта одна панель. Карточка, открытая при работающем ассистенте, встаёт в ту же панель с кнопкой «Назад к ассистенту».

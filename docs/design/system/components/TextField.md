# TextField

Поле ввода: поиск по библиотеке, вопрос ассистенту, пароль оператора.

Фон `surface`, рамка `line-strong`, при наведении рамка `ink-3`, в фокусе рамка `accent` и мягкое кольцо `accent-soft`. Подпись над полем (`pg-field__label`), подсказка или ошибка под ним; ошибка говорит, что исправить. Значок слева только у поиска. Многострочное поле — тот же класс на `textarea`, растёт по содержимому до шести строк.

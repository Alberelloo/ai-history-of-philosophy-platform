# Citation

Ссылка ответа ассистента на абзац источника или на утверждение онтологии.

Номер в круглой метке `accent` на `accent-soft`; при наведении метка заливается `accent`, рядом появляется подсказка с названием главы и началом абзаца. Нажатие открывает абзац с подсветкой `accent-soft`, затухающей за `dur-flash`. Ссылка на утверждение онтологии нейтральная (`pg-cite--statement`): фон `sunken`, рамка `line`. Номер ставится сразу после последнего слова предложения, без пробела, и не отрывается от него при переносе строки (`pg-nowrap`).

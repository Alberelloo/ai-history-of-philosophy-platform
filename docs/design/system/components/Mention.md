# Mention

Упоминание сущности в тексте источника: имя, понятие, учение, произведение, событие.

Пунктирное подчёркивание 1.5px в цвете семьи на 65% (`people`, `ideas`…), отступ 5px от базовой линии. При наведении или открытой карточке линия становится сплошной, слово получает фон `*-tint`. Читатель может спрятать подчёркивание в настройках (`data-mentions="quiet"` на контейнере текста): тогда упоминание видно только при наведении. Кликабельно только первое вхождение сущности в абзаце. Нажатие открывает `Popover` рядом со словом, не сдвигая текст.

## 2. Ведущая идея: страты-линзы вдоль оси времени

Вместо «облака узлов со связями» — **синхронологическая карта**: горизонталь = время (единый
backbone для всех линз), вертикаль разбита на **горизонтальные полосы-страты**, по одной на линзу.
Внутри полосы узел стоит на своём году; между полосами — жёлоба для межслойных связей.

Почему это правильно:
- **Убирает «клетку»**: координата узла теперь означает конкретное (год × категория), а не ячейку сетки.
- **Делает граф многоуровневым буквально**: каждая полоса — отдельная линза, её можно показать/скрыть/наложить.
- **«Взаимосвязи вдоль таймлайна»** — ровно то, что просил владелец: влияние читается слева-направо,
  межслойные связи (автор→труд, человек→эпоха) идут вертикально через жёлоба и легко читаются.
- **Аутентично «карте/атласу на столе».** Это реальный печатный жанр: *Joseph Priestley, «A Chart of
  Biography» (1765)* — жизни людей отложены горизонтальными отрезками вдоль оси времени; *Adams,
  «Synchronological Chart» (1871)* — страты истории. То есть мы не выдумываем «дашборд», а воспроизводим
  подлинный настольный картографический артефакт — это сильнее бьётся с арт-дирекцией, чем force-graph.

```
  рубрика · ЗАГОЛОВОК (стартовая сущность) · контекст        [ Линзы: ◉Люди ◉Контекст ◉Труды ]
 ┌──────────────────────────────────────────────────────────────────────────────┐  ← плита карты (нейтлиния)
 │  ЭПОХА ▸ Раннее Новое время        ▸ Просвещение                               │  КОНТЕКСТ (страта)
 │        ○1687 Principia      ○1789 ...                                          │  события-кольца, эпохи-пролёты
 ├────────────────────────────────────────────────────────────────────────────── │
 │   (Декарт)──┐                                                                   │  ЛЮДИ (страта)
 │   1596—1650 │影                                                                 │  медальон + линия жизни
 │             └──▶(Локк)────────▶(Юм)──────────▶(Кант)                            │  влияние: слева-направо
 │                 1632—1704      1711—1776       1724—1804                        │
 ├────────────────────────────────────────────────────────────────────────────── │
 │        ◈Разум          ▭Опыт о человеч. разумении    ▭Критика чистого разума    │  ТРУДЫ/МЫСЛИ (страта)
 │                        │авторство↑                   │авторство↑               │  труд на год издания + коннектор к автору
 └──────────────────────────────────────────────────────────────────────────────┘
    ├────────┬────────┬────────┬────────┬────────┬────────┤  ← общая шкала времени (вертикальные тики)
   1600     1650     1700     1750     1800   · без даты
```

## 3. Внешний вид: пересмотр узлов по типам (портреты сохраняем)

Общий принцип прежний (GD-08): тонкая чернильная линия, различимость по форме без цвета. Меняется не
грамматика знаков, а **как они стоят** (на году, в своей страте) и **линия жизни** у людей.

| Тип (family) | Было | Становится |
|---|---|---|
| **Человек** (person) | медальон в произвольной точке | **медальон-якорь + линия жизни** (рождение→смерть как горизонтальный отрезок), имя под медальоном, годы строкой. Самый читаемый элемент — усиливаем |
| **Понятие/идея** (ideas) | квадрат/ромб в произвольной точке | гравированный **ромб** на году появления, подпись рядом; в страте «Труды» |
| **Учение** (teachings) | ромб | **квадратная эмблема** на году, в страте «Труды» |
| **Произведение** (texts) | знак с загибом | **фолиант-марка** на году издания, название курсивом, вертикальный **коннектор авторства** вверх к линии жизни автора |
| **Эпоха** (history/epoch) | кольцо-точка | **пролёт-территория**: подписанный горизонтальный диапазон вверху, в страте «Контекст» |
| **Событие/место** (event/place) | кольцо | **кольцо-марка на году** + короткая подпись, страта «Контекст» |
| **Группа** (group, dense) | созвездие | созвездие-кластер в своей страте (для обзорного режима) |

Линия жизни — ключевая находка: она даёт **непроизвольную** X-координату человеку (его годы), сразу
объясняет расстановку и добавляет смысл (длительность, современники — кто жил одновременно, видно по
вертикали). Медальон ставим на удобном якоре (рождение либо «активный» год), остальное — тонкая линия.

## 4. Связи: «маршруты мысли», выпрямленные стратами

Проблема кривых концов уходит почти сама, потому что страты дисциплинируют геометрию:

- **Влияние внутри страты людей** (влиял→на кого): время гарантирует, что источник левее цели →
  **монотонная кривая слева-направо**, выходит из правого края медальона/линии жизни источника,
  входит в левый край цели. Привязка — к **истинному контуру** узла (точка пересечения направления
  связи с эллипсом медальона / прямоугольником знака, с учётом масштаба) — это чинит «концы не на узлах».
- **Межслойные связи** (автор→труд, человек→эпоха): идут **через жёлоб между полосами** — короткий
  вертикально-ориентированный коннектор (или мягкая S-кривая), а не через всё поле. Читаются как
  «спуск» из слоя в слой.
- Наконечник — на контуре цели; подпись отношения — на разрыве линии (как в GD-10/11); семейство
  (цвет) и статус (verified/sourced/generated — сплошная/пунктир + знак) сохраняются без изменений.
- Параллельные связи разводятся в жёлобе; петля — малая дуга. **Greedy-обходчик препятствий больше не
  нужен** — геометрия предсказуема, что убирает остаточные баги round-2/3 (заезд в bbox подписи и т.п.).

> Точная причина «концы не на узлах» (подтверждено чтением кода): `anchorOn()` считает точку выхода по
> **прямоугольной** аппроксимации узла (а не по эллипсу медальона / ромбу / многоугольнику) и
> **принудительно инвертирует вертикаль** (`if(ey>0)ey=-ey` — связь всегда «как будто сверху»),
> плюс фиксированный `pad=4`. Фикс: считать пересечение направления связи с **истинным контуром**
> формы (параметрически для эллипса/ромба/прямоугольника) с учётом масштаба, без инверсии вертикали.

## 5. Материальность: стол и карта (усилить)

- **Стол (орех).** Глубже и теплее: многотоновый орех, мягкий **сатиновый** направленный блик (не глянец),
  более выраженная, но мягкая **контакт-тень** карты, лёгкая фаска/кромка у края карты. Dark — графит.
- **Карта вместо «таблицы».** Убрать квадратный гратикюль как мешанину ячеек. Разлиновка становится
  **осмысленной**: вертикальные линии = **тики времени** (шкала-backbone), горизонтальные = **границы
  страт** (как нотный стан). Плюс слабые складки раскладного листа и тональная вариация бумаги.
  Нейтлиния-плита карты остаётся (владелец подтвердил). Так «разлинованность» получает смысл: время × слои.

## 6. Механика линз (как переключать/накладывать)

Модель состояния: `state.lenses = { people:true, context:true, works:true }` (независимые тумблеры в
строке управления, шрифт Onest, как UI — GD-03). Плюс производное `lensOf(type)` для каждого узла.

- **Solo (одна линза):** включён один тумблер → его страта на всю высоту, остальные свёрнуты в тонкие
  подписанные ленты-заголовки (ориентация сохраняется), их узлы скрыты.
- **Overlay (несколько):** включены 2–3 → активные страты делят высоту; межслойные связи рисуются.
- **Подсветка взаимосвязей:** выбор сущности → приглушение неродственного и **подсветка связей через все
  страты** (Кант → его линия жизни, его труды ниже, его влияния по горизонтали, его эпоха выше). Это и есть
  «одновременно с разных сторон подсвечивать взаимосвязи вдоль таймлайна».
- **Обрезанные связи:** если один конец в свёрнутой страте — у границы полосы рисуем «корешок + счётчик»
  (есть ещё N под этой линзой) → приглашение включить линзу. Честно и не прячет данные (GD-15).
- **Движение:** перестройка страт 160–240 мс, `prefers-reduced-motion` → мгновенно (GD-16).

Технически (ложится на текущий код, см. §7): `layout()` переписывается в «страта по линзе + укладка в
дорожки (lanes) по году», ось времени переиспользуется, добавляются тумблеры-линзы в `#controls` и поле в
`state`, `render()` перестраивает полосы. `window.atlas` API расширяется (`setLens`, `toggleLens`).

## 7. Как ложится на текущий макет, арт-дирекцию и GD

**Переиспользуем:** материал стола/листа и тени, нейтлиния, шрифты Literata/Onest, палитры семейств и
статусов (GD-05/11), портреты-дуотон, маргиналии, ось времени (повышается в ранг backbone), `window.atlas`,
набор fixtures (те же данные, year/dates уже есть).

**Меняем в коде:** `layout()` (страты+дорожки), маршрутизацию связей (band-aware, точный `anchorOn`),
`drawAxis()` (полноценная шкала + границы страт + пролёты эпох), UI линз + состояние, фон `.graph`
(семантическая разлиновка вместо квадратного гратикюля).

**Влияние на GD (нужно будет обновить ТЗ):**
- GD-03 «композиция»: сеть-облако → **страты-карта**; главный объект по-прежнему карта (не декор).
- GD-01/06а: образ уточняется — «синхронологическая карта/хронологический атлас на столе».
- GD-08/10/11 (формы, геометрия рёбер, статусы) — в основном сохраняются; добавляется «линия жизни» и
  band-aware маршрутизация.
- Контроль: сохранить ≥3 семейства в кадре, grayscale-иерархию (TC-07), WCAG, min hit-area, reduced-motion.

**Риск-развилка (главный вопрос владельцу):** это **смена жанра** — от свободного node-link графа к
хронологической карте-страте. Так буквально выполняется «многоуровневость вдоль таймлайна», но это
заметный поворот. Альтернатива — оставить свободный граф, но добавить переключаемые/накладываемые
слои-линзы без жёсткой временной оси (меньше структуры, но ближе к нынешнему виду). Нужно подтверждение.

## Записка: что изменено и почему

Файлы: `style.css` (основное), `index.html` (+1 декор-div). `app.js`/`fixtures.js` — не тронуты;
геометрия графа, формы знаков, маршрутизация связей без изменений.

1. **Стол → морёный орех с лампой и виньеткой.** Был плоский `#302e2a`-прямоугольник («рамка на
   рамке»). Стало: тёплый деревянный слой + продольная микротекстура + тёплый направленный свет
   сверху-слева (screen) + виньетка к краям (multiply) + тонкое зерно. `--graph-desk`-токен не тронут
   (материал — декоративные слои поверх). В dark — холодный графит без свечения/сепии.
2. **Лист → материал, а не карточка.** Тонкий градиент света по бумаге (не влияет на контраст),
   зерно на свободном поле (маскируется непрозрачными подписями), многослойная **направленная** тень
   (контакт+ambient, свет сверху-слева), стопка-толщина переработана (смещения (3,4)/(6,9), дальний
   слой тонируется к столу).
3. **Сгиб** из невидимой 10px-полоски → 18px с световым ребром и теневой впадиной у левого поля.
4. **Карта на столе (референс Civilization).** Слабый **гратикюль** (сетка меридианов/параллелей)
   под сетью → граф читается как стратегическая карта территории идей. Тонкая двойная **нейтлиния**
   (рамка плиты карты) внутри края листа. Оба слоя — декоративные, `pointer-events:none`, вне a11y,
   низкоконтрастные, авто-инверсия по теме.
5. **Тёмная тема** — настоящий графит (стол + лист + усиленная направленная тень), не плоский дашборд.
6. **GD-06 в ТЗ** синхронизирован с новыми числами (тень/зерно/сгиб/свет стола) + добавлен GD-06а
   (картографический слой). Отмечено, что TC-06/TC-07 нужно перепройти на фактическом рендере.

## Диагноз: почему выглядит плоско и нереалистично

1. **Стол — плоская тёмная рамка** (`--graph-desk` сплошной цвет). Нет поверхности/света/материала →
   «рамка на рамке», та самая ошибка Ф0 из §1 арт-дирекции.
2. **Лист без материала**: плоский цвет + дженерик box-shadow + грубые смещённые копии
   (`::before/::after`) вместо реальной толщины бумаги. Нет зерна, нет градиента света, нет тёплой вариации.
3. **Нет источника света** — равномерная заливка = «рендер прототипа».
4. **Тень симметричная дженерик** — читается как Material-карточка, а не бумага на столе.
5. **`.fold`** практически невидим — сгиба раскладного листа нет.
6. **Тёмная тема** — инверсия на почти-чёрном, тот же плоский дашборд.

## Что НЕЛЬЗЯ ломать (жёсткие рамки)

- GD-04 токены `graph-*`, GD-05 палитра связей (WCAG-числа) — без пересчёта контраста не трогать.
- GD-06 материал: радиус листа 3px, тень light .18 / dark .32, фактура opacity ≤0.025/0.015,
  сгиб ≤12px, декор `pointer-events:none` и вне accessibility tree. **Это и есть предмет вопроса 1 ниже.**
- GD-07 только Literata/Onest, таблица кеглей; GD-08 формы/размеры знаков; GD-16 тайминги.
- Пройденные кейсы: TC-06 (контраст на реальном фоне), TC-07 (grayscale-иерархия),
  TC-01/03/05 (один лист без фона/тени у графа и заметок), TC-21 (смена темы без промежуточного цвета),
  TC-22 (zoom 200%), TC-24 (монограмма без портрета). Геометрия графа/маршрутизация — не трогаем.

## Главный рычаг

Переработка **сцены**: стол (материал + свет + виньетка), лист (толщина, зерно на свободном поле,
градиент света, направленная тень, сгиб), тёмная тема как настоящий графит. Граф-печать почти не трогаем.

## Дополнение владельца (2026-11-17): референс Civilization — «карта на столе»

Источник: `/root/civ-reference.md`. Не просто лист атласа, а **стратегическая карта территории
идей, разложенная на столе философа**; граф строится ПОВЕРХ карты и читается как карта —
картографическая глубина, ощущение территории и масштаба, лёгкий топ-даун. Сохранить принятые
решения (морёный орех, свет сверху-слева, статичный кадр).

Как воплощаю в рамках арт-дирекции (без «пиратской карты», без текстуры поверх текста/линий,
граф доминирует, grayscale-иерархия держится):
- лист = **карта-плита**: очень слабый картографический **гратикюль** (сетка меридианов/параллелей)
  на свободном поле, за графом; подписи-плашки его перекрывают → текст чист;
- тонкая **нейтлиния** (рамка плиты карты) по периметру листа — сдержанно, как печать карты, не UI-рамка;
- всё декоративное: `pointer-events:none`, вне a11y tree, низкий контраст.
- РИСК/ВОПРОС: нейтлиния vs правило «нет рамки вокруг SVG» — делаю по периметру ЛИСТА, не вокруг графа;
  вынесу на подтверждение владельцу со снимком.

## Решения по картографическому слою (2026-11-17)

- **Нейтлиния — оставить как сейчас** (двойная рамка-плита карты по периметру листа). Подтверждено владельцем.
- Гратикюль — текущая сила ОК (подтверждена визуально на genesis/specimens/dense); при желании легко подстроить
  через токены `--graticule`/`--graticule-major`.

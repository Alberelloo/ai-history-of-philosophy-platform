# Журнал цикла визуальной доводки — сцена «стол философа»

Инструкция: `/root/design-cycle.md` (до 5 прогонов: проверка в Playwright → улучшения → документ →
правки + проверка корректности; коммит и пуш после каждого прогона).

**Объект цикла:** `docs/design/system/previews/graph-f02-lenses/desk.html` — текущий макет со столом и
линзами. В инструкции указан `graph-f02/index.html`, но направления цикла (связи в линзах, страты,
таймлайн) относятся к макету с линзами; старый `graph-f02` (35/35) не трогаем.

**Проверка:** Playwright (`playwright-core`) + headless Chromium. Скрипт рендерит 1440×1080 и 1280×900 в
светлой и тёмной теме, кроп графа 2×, и проверяет корректность: JS-ошибки, упавшие запросы,
загрузка рукописного шрифта, горизонтальный скролл, геометрию (пересечения подписей между собой и с
линиями жизни). Kitesurf (преференция владельца для Playwright) не используется для визуальной
проверки: экспериментальный движок, SVG-фильтры сцены там не гарантированы.

**Референс таймлайна** `magisteria.ru/category/existentialism` недоступен с сервера и через WebFetch
(таймаут, вероятно гео-блок); опираемся на Пристли «Chart of Biography» и Histomap. Нужен скриншот от владельца.

## Прогон 1 — раскладка людей, таймлайн, доп. информация

| Нашёл | Решил | Почему |
|---|---|---|
| Линия жизни проходит прямо через имя каждого философа (зачёркнутый текст) | Линия жизни → **лента Пристли**: мягкая заливка рождение→смерть, имя внутри ленты, годы за её концом | Текст не пересекается линиями; жанр синхронологической карты Пристли |
| Линии жизни «технические»: серая черта с засечкой, как размерная линия чертежа | Лента с тонкой нижней кромкой, выбранный — плотнее | Чернила на бумаге, а не CAD |
| Пучок влияния жирный и идёт поверх подписи «Джон Локк»; связи цепляются к центрам медальонов под случайными углами | Влияние идёт **от ленты учителя** (конец жизни или момент «восприятия» ≈ 20 лет ученика) **к ленте ученика за его подписью**; толщина 4→1.2 px | Нити короткие, текут вперёд во времени, не трогают текст |
| Нить Декарт→Локк пересекает подпись Спинозы | **Упаковка дорожек**: Спиноза (1632–1677) и Юм (1711–1776) делят дорожку; дорожек 4 вместо 5 | Приём Пристли; цепочка идёт по соседним дорожкам; больше воздуха |
| Приглушённый контекст (эпохи, Спиноза, чужие труды) при 0.26 на фактурной бумаге — грязные пятна | Эпохи — полноценный фон; «чужое» — 0.42–0.5 | Контекст должен читаться как фон, а не как смазанное |
| Значки трудов — «иконки файлов» из UI | Закрытая книга сверху (корешок + строки), понятие — ромб-печать | Предметы стола, а не интерфейс |
| Названия трудов обрезаны многоточием и налезают друг на друга | Перенос в 2 строки (ширина 150), ряды раскладываются по фактическим ширинам без столкновений; год мелко над значком | Полное название, ноль коллизий |
| Двойная пустая линейка внизу (граница страты + ось) | Одна **гравированная масштабная линейка карты**: двойная черта, чередующиеся заливки по 25 лет, годы старостильными цифрами Literata | Картографический приём вместо UI-оси |
| Свёрнутая линза — две линии и три точки | Ромбы-события + подпись «3 события · линза свёрнута» | Понятно, что слой есть, но скрыт |
| Годы Канта упираются в край листа; год «1781» перечёркнут нитью; черта под «Критикой» перечёркивает год | Годы внутри конца ленты, если не влезают; у выбранного труда год сбоку; рукописные пометки считаются от раскладки | Ничего не режется и не перечёркивается |

**Техника:** граф сцены вынесен в `desk-chart.js` (утверждённый ранее кадр `trial.html` не тронут).

**Проверка корректности:** JS-ошибок 0, упавших запросов 0, Bad Script загружен, горизонтального
скролла нет (1440 и 1280, light/dark), пересечений «подпись × линия жизни» 0, пересечений подписей
данных 0. Остаются 3 «пересечения» строк рукописных заметок — это повёрнутые рамки соседних строк,
визуально строки не касаются (проверено на кропе 2×).

**На следующие прогоны:** связи стали тихими (прогон 2 — стиль связей и линзы); переключатели линз —
UI-«таблетки» (прогон 3 — структура вокруг графа); граф мелковат относительно листа (прогон 4).

## Прогон 2 — связи и их язык в разных линзах

| Нашёл | Решил | Почему |
|---|---|---|
| После прогона 1 влияния стали короткими тугими «крючками» — цепочка не читается как поток | Плавная дуга: уход по касательной, приход круто сверху на ленту ученика; лента 4.6→1.3 px | Поток через карту, а не скобка; крутой приход не задевает имя ученика |
| Точка выхода влияния — смерть учителя: смыслово неверно | Выход — **год ключевого труда учителя** (Декарт 1637, Локк 1690, Юм 1748) | Влияние идёт через труды; связь людей и трудов передана положением, без лишних линий |
| Одиночная ровная лента — «не волшебно» | Две волосяные пряди-спутника (пучок) + две искры вдоль пути, градиент «синий → киноварь», мягкое свечение | Эстетика «нитей/созвездий» из ресёрча, без тяжёлого glow |
| Приглушённая связь Декарт→Спиноза почти невидима | Пунктир 0.5 | Контекст читается, но не спорит с фокусом |

**Решение по межслойным связям** (вопрос инструкции «связывать ли труды + людей + события»):
по умолчанию **не связываем линиями** — страты остаются визуально раздельными. Межслойные связи
проявляются только при фокусе, и у каждой линзы свой язык:
- **Люди** — влияние: киноварный поток между лентами (с прядями и искрами);
- **Труды** — авторство: бирюзовая пунктирная нить от ленты автора к выбранному труду + гало;
- **Контекст** — без линии: эпоха, на которую пришлась жизнь выбранного, подсвечена (заливка +
  выделенная подпись) и отмечена короткой пунктирной засечкой у медальона;
- **События мира** — в свёрнутой линзе не связываются; при раскрытии — тот же приём, что у контекста.

Так при выборе персоны видно сразу три стороны (откуда мысль, что написано, в какую эпоху), а сеть
не превращается в паутину.

**Проверка корректности:** 0 JS-ошибок, 0 упавших запросов, без горизонтального скролла (1440/1280,
light/dark), 0 пересечений «подпись × линия жизни», подписи данных не пересекаются. Год выбранного
труда отодвинут от гало.

## Прогон 3 — структура вокруг графа, легенда, интерактив

| Нашёл | Решил | Почему |
|---|---|---|
| Переключатели линз — серые UI-«таблетки» над графом, оторваны от страт и **не работают** | Тоггл-«глаз» у подписи своей страты в левом поле (как строки слоёв в легенде карты); клик сворачивает страту в ленту 22 px, **остальные забирают её высоту** | Управление стоит там, где действует; просьба владельца «скрыть линзу — остальные расширяются» |
| Нигде не объяснено, что выбрано и почему подсвечено | **Сноска «Выбрано»** в правом поле шапки: «Влияли: Декарт → Локк → Юм», «Труды: …», «Эпоха: …» — с теми же значками, что на карте | Подсветка проговорена словами; сноска одновременно легенда фокуса |
| Нет расшифровки символов | **«Условные знаки»** внизу листа: годы жизни, влияние, труд, понятие, событие, шаг линейки 25 лет | Картографическая легенда атласа |
| Выбрать другого философа нельзя | Клик или Enter по философу — проявляются его влияния (вверх по цепочке и ученики), труды, эпоха; клик по полю листа или Esc — снять выбор; без выбора — нейтральные потоки и подсказка «Как читать» | Подсветка по клику, о которой просил владелец |
| Подписи страт в поле переносились неряшливо («КОНТЕКСТ ·» / «ЭПОХИ») | Короткие имена линз: События · Эпохи · Люди · Труды | Одна строка, без висящих знаков |
| Раскрытые «События мира»: «Французская революция» вылезала за край листа; первая попытка (подпись влево) наложилась на «Энциклопедию» | Подпись прижимается к правому полю и уходит под кольцо | Без выхода за лист и без наложений (проверено кропом 2×) |

**Проверка корректности (Playwright, `cycle/ixn.js`):** 0 JS-ошибок.
- Линзы: «События» вкл → высоты страт 22/57/287/125 → 49/54/271/118, появились 3 кольца, `aria-pressed=true`;
  «Труды» выкл → 62/68/340/22, значков трудов 0; возврат восстанавливает исходные высоты;
  последнюю включённую линзу выключить нельзя.
- Выбор: клик по Декарту → выбран, `aria-pressed=true`, сноска «Повлиял на: Локк, Спиноза · Трудов в
  выборке нет · Эпоха: Научная революция», заголовок «Рене Декарт»; Enter на Локке → выбран, фокус
  сохранён после перерисовки; клик по полю → выбор снят, приглушений 0; Esc → снят.
- Рендер 1440/1280 × light/dark: без горизонтального скролла, 0 пересечений «подпись × линия жизни».

## v3 — отзыв 2026-11-18: «мало бумаги» и «подписи сделаны под Канта»

**Отзыв:** (1) слишком много стола, мало бумаги — главный фокус на таймлайне, область нужно расширить;
(2) непонятно, подстраиваются ли подписи на таймлайне или это только для скетча: кадр сделан под Канта.

**Ответ на (2) — что было:** граф (ленты, нити, труды, эпоха, сноска «Выбрано», заголовок) уже строился
из данных и менялся при выборе. Но рукописные пометки были вписаны руками под Канта: цитата про Юма в
фиксированных координатах, «а Спиноза? →», карточки на столе с вопросами Канта. При выборе Локка на
листе оставалась цитата Канта.

| Нашёл | Решил | Почему |
|---|---|---|
| Лист — 65 % экрана на 1440 и 41 % на 1920, график — 42 % и 26 % | Лист почти во всю ширину (поле стола 40–120 px), график в реальных пикселях листа (`W` = ширина, `BODY` = остаток высоты окна, пересчёт при resize) | Шире лист — больше места на годы, а не крупнее шрифт. Теперь лист 85 %, график 60–65 % |
| Высота графа зависела от длины сноски «Выбрано» — при смене философа график прыгал на 40 px | Шапка фиксированной высоты | Выбор не должен двигать карту |
| Пометки вписаны под Канта | Пометки — данные: `notes[{about, lines, cite}]`, `about` — связь (`hume-kant`) или персона. Цитата выбранного — эпиграф на поле шапки, всегда в одном месте | Работает для любого выбора; на плотных данных не ищет место в графе и не тянет стрелок через карту (пробовал автопоиск места со стрелкой — стрелки пересекали ленты) |
| Тема листа «Опыт или разум?» в фиксированных координатах | Ищет свободное место в страте трудов; места нет — не рисуется | Плотная страта трудов не получит наложений |
| Карточки на столе — вопросы Канта при любом выборе; справа обрезаны краем экрана посреди слова | Карточки следуют за выбором: главный вопрос философа и его труды «к чтению» (нет трудов — карточки нет); перенесены под лист, к очкам и письму | Стол тоже «читает» выбор; текст не режется |
| На 1280×800 вторая строка названия труда касалась шкалы | Минимальная высота страты трудов 136 px | Два ряда двухстрочных названий помещаются |

**Проверка:** 0 JS-ошибок; без горизонтального скролла; 0 пересечений «подпись × линия жизни»;
единственное «пересечение» — две строки повёрнутой рукописной темы (ложное, как раньше); интеракции
проходят; контраст 0 из 48 ниже 4.5:1. Кадры выбора: `cycle/v3-sel-descartes.png`, `v3-sel-locke.png`,
`v3-sel-spinoza.png`.

**Что ещё не проверено:** плотные реальные данные (десятки философов, сотни трудов). Нужен стресс-кадр
на выгрузке онтологии: упаковка лент по дорожкам, отбор подписей трудов по важности, порог, когда
страта сворачивается в «N трудов».

**Откуда в продукте берутся пометки:** цитата — из источника с выходными данными (онтология + RAG);
вопрос на карточке — редакторская выжимка. Если текст достроен LLM и не проверен человеком, он

### Рендер от данных

`desk-chart.js` больше не содержит координат и данных: всё из `desk-data.js` (`?data=demo|dense`).
- Дорожки людей — жадная упаковка по году рождения с учётом длины подписи.
- Подписи трудов: приоритет — труды выбранного, затем ключевые; до 2–3 рядов; нет места — тонкая
  отметка без подписи (название — во всплывающей подсказке).
- События: «год событие» в два ряда; подпись не налезает на чужие кольца; нет места — только кольцо.
- Эпоха: подпись скрывается, если не помещается в пролёт.
- Выбор показывает прямые связи (учителя и ученики), концы нитей раздвинуты вдоль ленты.

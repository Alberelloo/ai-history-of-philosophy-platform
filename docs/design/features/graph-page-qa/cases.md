# Кейсы приёмки графа Ф0.2

Статус: **запланированы, не выполнены**. 2026-11-14.
Источник: [дизайн-ТЗ](../graph-page-design.md). Это дизайн-кейсы изолированного preview,
не замена продуктовым OpenSpec-кейсам. Новые интеракции обозначены как контракт будущего
продукта; до продуктового кода переносятся в OpenSpec-изменение.

## Фикстуры, которые должны быть подготовлены до макета

| ID | Данные |
|---|---|
| F1 / genesis | 8 узлов: 4 person включая старт Канта, 2 concept, 2 work; 10 утверждений допустимых типов из семейства genesis по реестру. Равные и неизвестная даты. Статусы 4 verified, 3 sourced, 3 generated. Названия/отношения помечены демонстрационными; все узлы достижимы от старта |
| F2 / specimens | 5 семейств и 6 цветов связей, все 18 комбинаций «семейство связи × статус» в отдельном демонстрационном листе. Включены doctrine, неизвестный тип, group, отсутствие портрета, длинное имя |
| F3 / dense | 48 узлов в 3 группах, две свёрнуты; фиксированный seed/координаты; смешанные статусы, параллельные рёбра, петля, длинные подписи |
| F4 / states | Пусто, один узел, фильтры скрыли всё, ошибка, LLM недоступна, достройка, лимит |

Наборы не являются историческим датасетом. Для реально процитированного материала нужны
источник и ссылка на абзац; иначе явно «Демонстрационная цитата». Фикстуры сохранять отдельно
от кода представления, с ID узлов/связей для воспроизводимых тестов.

## Обязательный комплект доказательств

- F1: 1440×900 и 1024×768 × light/dark × RU/EN = 8 кадров.
- F1: 1280×900 pinned/unpinned и 1920×1080, light = 3 кадра.
- F1: selected edge + selected non-start node + keyboard focus = 3 кадра, light 1440.
- F2 specimen: light/dark = 2 кадра; F3 overview light/dark + раскрытый light = 3 кадра.
- F4: коллаж/набор всех восьми состояний GD-15 с читаемыми подписями.
- Reduced motion, grayscale без фактуры, 200% browser zoom = ещё 3 контрольных кадра.
- Отчёт: case → pass/fail/not-tested → путь кадра/лога → finding ID. Снимки должны быть
  действительно открыты проверяющим. Наименование light/dark проверять по computed style,
  а не порядку нажатий переключателя (в Ф0 имена файлов были ненадёжны).
- Художественные пять вопросов GD-17 — отдельная оценка, не вывод браузерного теста.

До реализации экспорт/реальный streaming API и производительность не заявляются проверенными.
Они переходят в продуктовые кейсы; визуальный preview не заменяет E2E продукта.

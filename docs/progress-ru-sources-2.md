## Проблемы адаптеров

- Wikisource: поле `ПЕРЕВОДЧИК` в «Отексте» часто содержит имя автора (Ницше, Шиллер, Гексли) — переводчик == автор; правится вручную.
- Страницы-оглавления: Макиавелли «Государь» (три орфографических варианта одного издания — оставлен один через `override.files`), «Вехи» (только оглавление; статьи на отдельных страницах — `override.files` собраны вручную).
- Wikidata по имени ошибается (Глебова ум. 1985); для русских авторов совпадения верные, но фамилия-имя иногда в виде «Лопатин, Лев Михайлович» (id содержит отчество).
- `catalog add` по красной ссылке даёт `ValueError: нет страницы` — запись не создаётся.
- Среда: Python не может писать в scratchpad; тексты в репозиторий не кладутся.

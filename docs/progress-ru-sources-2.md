# Прогресс: русские источники, второй проход по ru.wikisource

Ветка `claude/ru-sources-wikisource-2` (от `origin/claude/ru-sources-catalog`). Только черновики (`review.status: draft`), без `approve`. Журнал первого прохода: `docs/progress-ru-sources.md`.

## Как проверить

`PYTHONPATH=src python -m philograph.library.catalog validate`. Записи второго прохода идут после `plato-*`/`s-sobranie-sochineniy-t-10-archive` (первые 170 записей — прежние).

## Как возобновить

1. Прочитать этот файл и `git log`.
2. Дерево категории «Философия» (подкатегории) получено через MediaWiki API; список страниц повторно: `list=categorymembers`, 1 запрос/с.
3. Для каждой страницы: заголовок `Отексте` (переводчик, год) через `action=query&prop=revisions`; затем `catalog add <url> --kind ...`; затем правка `override.metadata` (название, авторы с годами смерти, переводчик, год), `license`, `review.note`.

## Правила отбора (повторено)

- Переводчик с неустановленным годом смерти, советские/после 1955 — запись не создаётся (в отчёт «отклонено»).
- Исключение, оговорённое в note: перевод опубликован не позже ~1880 г. (переводчик взрослый, не мог дожить до 1955).

## Проблемы адаптеров

- Wikisource: для «Отексте» поле `ПЕРЕВОДЧИК` часто содержит имя автора (Ницше, Дидро, Шиллер, Гексли) — после `add` переводчик == автор; правится вручную.
- Страницы-оглавления с редакциями (Макиавелли «Государь»): в `files` попадают все орфографические варианты одного издания; оставлен один через `override.files`.
- Wikidata по имени сопоставляет неверно (Глебова ум. 1985).
- В среде нельзя писать из Python в scratchpad; тексты не сохраняются.

# Запуск: сервер, домен и ключи

Список всего, что нужно для развёртывания публичного сервера и боевых моделей (часть
изменения `pilot-launch`, раздел 3, и `pilot-launch` 2.2 — провайдер эмбеддингов).
Составлен по `docs/operations/runbook.md`, `.env.example`, `config/llm.yaml`, ADR-0002 и
спецификациям; каждая строка — с требованием, которое она закрывает.

## 1. Сервер и домен

| Что нужно | Зачем | Требование |
|---|---|---|
| VPS или выделенный сервер: 2 vCPU, 4 ГБ RAM, 40 ГБ SSD (без локальных эмбеддингов; с ними — 8 ГБ RAM) | все сервисы плюс Postgres и реверс-прокси | `deployment` / «Публичный адрес по HTTPS» |
| Ubuntu 22.04 или 24.04, Docker Engine и Compose v2 | `scripts/deploy.py update <версия>` собирает образ и поднимает сервисы | `deployment` / «Обновление с миграциями» |
| DNS: A (и AAAA, если есть IPv6) на домен и `www` → IP сервера | Caddy выпускает сертификат по домену | `deployment` / «Публичный адрес по HTTPS» |
| Открыты только 80 и 443; 22 — по вашему IP или через SSH-ключ | внутренние сервисы не видны снаружи | `deployment` / «Внутренние части не видны снаружи» |
| CDN с передачей страны читателя (заголовок, у Cloudflare — `CF-IPCountry`) | без страны запросов ограниченные источники закрываются всем | `regional-access` / «Шлюз доступен только через CDN» |
| Диапазоны IP CDN (для фаервола и `PHILOGRAPH_CDN_IPS`) | Caddy верит заголовку страны только от CDN | `regional-access` / «Гарантия, что заголовок от CDN» |
| Внешнее хранилище копий: отдельный бакет S3 или смонтированный каталог | копии базы и файлов, шифруются | `backup-and-recovery` / «Ежедневные копии» |
| Канал оповещений: бот Telegram (токен и chat_id) или вебхук | сбои, истечение копий, приближение к бюджету | `operational-alerts` / «Канал оповещений» |

## 2. Ключи и секреты

Все — в `.env` на сервере (файл в репозиторий не попадает).

| Переменная | Что это | Закрывает | Как получить |
|---|---|---|---|
| `DEEPSEEK_API_KEY` | ключ для моделей `deepseek-flash` и `deepseek-v4-pro` | `llm-gateway` / «Роли моделей» | кабинет DeepSeek |
| ключ провайдера эмбеддингов | **самый важный выбор**: без него смысловой поиск работает на заглушке | `paragraph-indexing` / «Версия модели эмбеддингов», `paragraph-search` / «Гибридный поиск», ADR-0002 | см. раздел 4 |
| `POSTGRES_PASSWORD` | пароль базы | `deployment` / «Внутренние части не видны снаружи» | сгенерировать |
| `PHILOGRAPH_VISITOR_SECRET` | соль обезличивания посетителей (лимиты) | `abuse-protection` / «Без персональных данных» | длинная случайная строка |
| `PHILOGRAPH_INTERNAL_TOKEN` | токен внутренних метрик и оповещений | `observability` / «Журнал срабатываний» | длинная случайная строка |
| `PHILOGRAPH_OPERATOR_PASSWORD_HASH` | хеш пароля оператора для `/internal/review` | `operator-access` / «Вход оператора» | `python -c "from philograph.operator.access import hash_password; print(hash_password('…'))"` |
| `PHILOGRAPH_BACKUP_KEY` | ключ шифрования копий; хранить отдельно от копий | `backup-and-recovery` / «Шифрование копий» | `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` |
| `PHILOGRAPH_DOMAIN` | домен для Caddy | `deployment` / «Публичный адрес по HTTPS» | ваш домен |
| `PHILOGRAPH_REGION_HEADER` | имя заголовка страны (`CF-IPCountry`) | `regional-access` / «Регион читателя определяет шлюз» | ваш CDN |
| `PHILOGRAPH_CDN_IPS` | диапазоны IP CDN через пробел | `regional-access` / «Гарантия, что заголовок от CDN» | документы CDN |
| `PHILOGRAPH_ALERT_TELEGRAM_TOKEN`, `PHILOGRAPH_ALERT_TELEGRAM_CHAT` | канал оповещений (или `PHILOGRAPH_ALERT_WEBHOOK`) | `operational-alerts` / «Канал оповещений» | BotFather |
| `PHILOGRAPH_BACKUP_DIR` или `PHILOGRAPH_BACKUP_TARGET` | куда класть копии | `backup-and-recovery` / «Ежедневные копии» | бакет или смонтированный каталог |

Необязательно, но стоит выставить сразу:
`PHILOGRAPH_RATE_PER_SECOND`, `PHILOGRAPH_RATE_BURST`, `PHILOGRAPH_LIMIT_ASK/GRAPH/DESCRIPTION`
(лимиты посетителя, `abuse-protection`), `PHILOGRAPH_VISITOR_SECRET`.
**`PHILOGRAPH_REGION_FALLBACK` в продакшене оставить пустым** — иначе ограничение регионов обходится.

## 3. Чего сейчас не хватает в коде для продакшена

| Пробел | Последствие | Требование |
|---|---|---|
| В `config/llm.yaml` роль `embeddings` указывает на заглушку `embeddings-stub` | смысловой поиск на боевом сервере не работает, только по словам | `paragraph-indexing` / «Версия модели эмбеддингов» |
| `scripts/deploy.py` проверяет только настройки региона, но не требует ключей и секретов | сервер поднимется без `DEEPSEEK_API_KEY` и будет отвечать ошибками | `llm-gateway` / «Единственная точка вызова моделей» |
| Нет готового «здоровья» для проверки провайдера и квоты эмбеддингов | об отсутствии ключа узнаём из первых ответов, а не при запуске | `service-runtime` |

Эти три пункта — отдельная небольшая работа; предлагаю сделать до первого развёртывания.

## 4. Провайдер эмбеддингов: что решить и что нужно

ADR-0002 оставил выбор открытым: подключаем провайдера за ролью `embeddings` и **замеряем**
на наборе вопросов пилота (recall@k и MRR на русских и межъязыковых запросах).

| Кандидат | Что нужно от вас | Плюсы | Минусы |
|---|---|---|---|
| OpenAI `text-embedding-3-small` | аккаунт и ключ | дёшево, мультиязычный | текст уходит в США |
| Jina embeddings v3 | аккаунт и ключ | сильный мультиязычный, длинный контекст | отдельный аккаунт |
| Cohere `embed-multilingual-v3` | аккаунт и ключ | сильный мультиязычный | дороже |
| Локальная `bge-m3` или `multilingual-e5` | **только сервер**: 8 ГБ RAM, контейнер модели | текст не уходит наружу, нет расходов | нужен процессор и память, качество на древнегреческом мерить |

У DeepSeek API эмбеддингов нет (ADR-0002), поэтому ключ DeepSeek эту роль не закрывает.

**Что предлагаю:** взять один внешний ключ (быстрее всего OpenAI small — самый дешёвый для
замера) и, если разрешение «внешняя обработка» для эмбеддингов нежелательно, рассмотреть
локальную модель. Замер даст числа; решение — за вами.

## 5. Спецификации, которые это закрывает

| Capability | Ключевые требования |
|---|---|
| `deployment` | «Публичный адрес по HTTPS», «Внутренние части не видны снаружи», «Автоматический перезапуск», «Обновление с миграциями», «Откат обновления», «Версия в журнале» |
| `regional-access` | «Регион читателя определяет шлюз», «Шлюз доступен только через CDN», «Неизвестный регион закрывает ограниченные источники», «Внешняя обработка закрытых источников» |
| `backup-and-recovery` | «Ежедневные копии», «Шифрование копий», «Проверка восстановления», «Неудачная копия» |
| `operational-alerts` | «Правила оповещений», «Канал оповещений», «Восстановление» |
| `abuse-protection` | «Лимит платных операций на посетителя», «Общий лимит частоты», «Без персональных данных» |
| `llm-gateway` | «Единственная точка вызова моделей», «Роли моделей», «Бюджеты и учёт стоимости», «Дневной лимит бюджета сайта», «Журнал вызовов» |
| `paragraph-indexing`, `paragraph-search` | «Версия модели эмбеддингов», «Стоимость и лимит индексации», «Гибридный поиск», «Деградация» |
| `observability` | журналы, метрики, оповещения; «Журнал срабатываний» |
| `operator-access` | «Вход оператора» |

## 6. Порядок шагов

1. Выбрать провайдера эмбеддингов (раздел 4) и получить ключ вместе с ключом DeepSeek.
2. Дописать три пробела из раздела 3 (роль `embeddings`, проверка обязательных секретов при
   `deploy update`, здоровье провайдера).
3. Приготовить сервер и DNS, поставить Docker, направить домен.
4. Заполнить `.env` на сервере по разделу 2, скопировать `.env.example`.
5. `python scripts/deploy.py update <версия>` — первое развёртывание; проверить сайт, `/internal/review`,
   копию и оповещение (runbook, «Первый запуск»).
6. Замер эмбеддингов на пилотном разделе (пункт 2.2 `pilot-launch`) и фиксация выбора в ADR-0002.
